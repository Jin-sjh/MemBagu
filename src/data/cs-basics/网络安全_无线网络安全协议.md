# 无线网络安全协议

## 【问题】
「哪种技术常用于保护无线网络安全？」这类题应该选什么？

## 【回答】
优先选 **WPA / WPA2 / WPA3**。选项里出现 **WPA2** 通常就是无线网络安全题的典型正确答案，它是长期的主流 Wi-Fi 安全标准；**WPA3** 是更新的继任者，安全性更高。

## 【问题】
Wi-Fi 安全协议的演进路线是怎样的？各代强度如何？

## 【回答】
演进顺序：

```text
WEP  →  WPA  →  WPA2  →  WPA3
```

| 协议 | 定位 / 现状 |
| --- | --- |
| **WEP** | **安全性很差，已淘汰**（RC4 密钥流弱点，可在几分钟内被破解） |
| **WPA** | **过渡方案**，在 WEP 之上打补丁（TKIP + MIC） |
| **WPA2** | **长期主流**，基于 AES-CCMP，是绝大多数设备的事实标准 |
| **WPA3** | **更新、更安全**，引入 SAE（对等实体同时认证）替代 PSK 握手，支持前向保密，抗离线字典爆破 |

## 【问题】
WPA2 和 HTTPS、SSL/TLS、SSH 怎么区分？是不是同一类东西？

## 【回答】
**不是同一类，保护的网络层次不同**。选择题里最容易混淆，按「保护对象」记：

```text
WPA2 / WPA3   → Wi-Fi 无线网络安全（链路层，Wi-Fi 接入与空口加密）
SSL / TLS     → 传输层加密（通用传输通道）
HTTPS         → Web 通信安全（HTTP over TLS）
SSH           → 远程登录 / 安全运维通道
```

判题方法：**题干问「无线网络安全」→ 选 WPA 系列；问「Web/网站通信安全」→ 选 HTTPS/SSL-TLS；问「远程登录」→ 选 SSH**。

## 【考察点】
选择题的高频干扰项配套记三个：
- WEP：已淘汰，**不能**作为「保护无线网络安全」的正确答案；
- HTTPS：是 Web 通信安全，不是无线局域网；
- SSH：是远程登录，不是无线局域网。
