# 方法重写与重载

## 【问题】
方法重写（Override）需要满足哪些条件？

## 【回答】
```text
父类：public void test()
子类：@Override public void test()
```

必须满足：

- **方法名相同**；
- **参数列表相同**（顺序、类型、个数一致，与参数名无关）；
- **返回类型相同或为协变返回类型**（子类返回值是父类返回类型的子类型）；
- **子类访问权限不能比父类更严格**（父类 `public`，子类不能是 `protected`/`private`）；
- **`final` 方法不能被重写**；
- **`private` 方法不存在真正意义上的重写**（子类不可见，子类里的同名方法是一个全新的方法）；
- **`static` 方法不能被实例方法重写**。
- 子类方法抛出的受查异常不能比父类更宽。

建议始终加 **`@Override` 注解**，让编译器帮忙校验签名是否真的匹配。

## 【问题】
static 方法可以被子类重写成实例方法吗？

## 【回答】
**不可以，编译直接报错**。示例：

```java
class A {
    static void test() {}
}

class B extends A {
    void test() {}   // 编译错误：无法重写静态方法
}
```

原因在于 **static 方法属于类，不属于对象**，不参与运行时的动态分派，因此不存在真正的多态重写。子类定义同签名的 static 方法时发生的不是 Override，而是**方法隐藏（Method Hiding）**：调用哪个版本由**引用的声明类型**决定，而不是对象的实际类型。

## 【问题】
重载 Overload、重写 Override、隐藏 Hiding 三者怎么区分？

## 【回答】
| 概念 | 发生位置 | 签名要求 | 绑定时机 |
| --- | --- | ---: | --- |
| 重载 Overload | **同一个类**（或父子类之间） | **方法名相同、参数不同** | **编译期静态绑定** |
| 重写 Override | **父子类之间** | 方法名与参数**完全相同** | **运行期动态绑定**（多态） |
| 隐藏 Hiding | 父子类之间的 **static 方法** | 方法名与参数完全相同 | 编译期按声明类型绑定 |

注意，**返回值不同不足以构成重载**，只有参数列表不同才算。

## 【考察点】
三个经典判断题陷阱：
1. 「static 方法可以被实例方法重写」→ **错**；
2. 「private 方法可以被重写」→ **错**（子类的方法与父类私有方法无关）；
3. 「返回值类型不同就是重载」→ **错**（重载只看参数列表）。
另外 `final`、`static`、`private` 三类方法都不参与真正的多态重写，这是判断是否构成 Override 的快速排除法。

## 【口诀】
```text
重载 Overload：同一个类，参数不同
重写 Override：父子类，参数相同
隐藏 Hiding：  static 方法
static 不参与真正的 Override
```
