# 参数化Memory

## 【问题】

什么是参数化 Memory？为什么说 Memory 是 LLM 自迭代中的外部 optimizer state？

## 【回答】

参数化 Memory 不只是"让模型记得更多"，而是让系统能把过去的交互、反馈、错误、偏好**压缩成未来可调用、可修正、可验证的更新结构**。工作定义为：

> **Memory = LLM 自迭代中的外部 optimizer state**

它保存的**不是历史记录本身**，而是历史经过**评价、归因、压缩**后形成的**可复用更新方向**。自迭代的本质，就是把海量经验压缩成可执行的更新方向——模型权重是慢变量，记忆是让系统能按经验持续修正行为的外部状态。

## 【问题】

LLM 时代之前的自适应元学习方法 MAML 的核心思想是什么？它如何体现"双层记忆"？

## 【回答】

MAML（Model-Agnostic Meta-Learning）训练的目标**不是"当前参数在任务上最好"**，而是"**经过少量梯度更新后最好**"的初始参数。对应**双层记忆**：

- **慢记忆 θ**：保存跨任务的共性，是元学习阶段学到的初始参数；
- **快记忆 θ'**：保存当前任务少量样本的信息，是对 θ 做几步梯度更新后的参数。

关键思想是学习一个"**容易被梯度读取的参数状态**"。局限在于：需要清晰的任务分布、二阶梯度计算成本高、对大模型做全参数 MAML 非常困难。

## 【问题】

Meta-SGD 在 MAML 基础上做了什么改进？

## 【回答】

Meta-SGD 在 MAML 基础上进一步学习"**更新方向和更新步长**"。它表明参数化记忆不只要记住"**站在哪里**"，还要记住"**新证据出现时往哪走、走多远**"——即更新策略本身也要可学习。

## 【问题】

Transformer 的参数本身能否视为 Memory？相关代表工作（Knowledge Neurons、ROME、MEMIT）是怎样的？难点在哪？

## 【回答】

可以，Transformer 的 **FFN 层可视为 key-value memory**。代表工作：

- **Knowledge Neurons**：某些事实的表达可归因到**少量 FFN 神经元**；
- **ROME**：将新事实以**低秩更新**写入中间层 MLP；
- **MEMIT**：把单点编辑扩展到**批量编辑**。

难点在于：Generalization（泛化）和 locality（局部性）**很难同时满足**；"定位在哪里"**不等于**"在哪里写最有效"；多次编辑会引入**干扰和遗忘**；事实编辑**不等于**完整知识更新；参数修改**不一定**比 in-context 更新更优。

## 【问题】

小参数增量（Prefix-Tuning、LoRA/QLoRA）如何作为"可插拔记忆"？有什么优缺点？

## 【回答】

- **Prefix-Tuning**：把 Memory 写成**可学习的连续上下文**（soft prompt）；
- **LoRA / QLoRA**：低秩增量 ΔW 作为**压缩后的任务记忆**，每个任务一个低秩矩阵。

优点：**可插拔、可回滚、多记忆并存**——不同任务可挂不同适配器，互不干扰。局限：**rank 是强约束**（低秩限制了表达能力），且**没有 Memory 生命周期管理**（不会老化、合并、遗忘）。

## 【问题】

参数冻结时模型是否仍在学习？ICL 的底层机制和争议是什么？

## 【回答】

**参数冻结 ≠ 不学习**；学习可以发生在前向传播的激活空间。ICL（In-Context Learning）的机制是 **induction heads**：`[A][B] … [A] → [B]` 的抽象模式匹配。从算法视角，ICL 可被理解为**隐式梯度下降 / 岭回归**（代表工作：Olsson et al.、Akyürek et al.、von Oswald et al.）。

**存在争议**：真实 LLM 的 ICL 是否真的等于梯度下降，目前**尚无定论**，更多是机制上的类比。

## 【问题】

Memory 压缩机制有哪些技术路线？共同原则是什么？

## 【回答】

- **Compressive Transformer**：显式上下文压缩记忆，其中 **attention-reconstruction loss** 效果最好；
- **Gist Tokens**：把 prompt 压缩进**少量 gist token 的隐藏状态**；
- **AutoCompressors**：把长上下文**递归压缩成 summary vectors**；
- **ICAE**：把上下文压缩成 **memory slots**；
- **LLMLingua / LongLLMLingua / LLMLingua-2**：压缩回**离散文本**，适合黑盒模型。

共同原则：压缩结果要**面向模型**（让模型好用），而不只面向人；压缩**必须任务相关**，不能脱离任务做无损裁剪。

## 【问题】

显式参数化记忆层有哪些代表工作？各自解决了什么？

## 【回答】

- **Product Key Memory**：大容量、稀疏读取，**容量与计算解耦**；
- **Memory Layers at Scale**：在 **128B 参数规模**验证记忆层收益**集中于事实类任务**；
- **PEER**：**百万级细粒度专家**，统一了"记忆槽位"和"MoE expert"两个概念；
- **Sparse Memory Finetuning**：用离散地址实现**可写、可定位、低干扰**的持续学习。

## 【问题】

什么是测试时学习（TTL / TTT）？有哪些代表工作和统一框架？边界在哪？

## 【回答】

TTL（Test-Time Learning）的起点问题是：**推理时的梯度从哪来？** 代表工作：

- **Dynamic evaluation**：用语言建模 loss 做测试时更新；
- **TTT-2020**：没有监督信号时，用**旋转预测**制造信号；
- **ARC-TTT**：把测试时训练用到 LLM，达到**人类平均分**；
- **TTT Layers**：隐藏状态本身是一个**可学习的模型**；
- **Titans**：给写入配上**动量和遗忘**；
- **FlashMemory**：生产系统**不做写路径更新**，而是优化**读路径预取**。

统一框架：**线性注意力 = 一步 GD（梯度下降），softmax attention = 核回归**。边界：规模证据停留在**学术档**、状态**无法跨会话**、评测体系**不完整**、**安全投毒面扩大**。

## 【问题】

为什么说 RAG 是把记忆放在参数之外？2026 年以来 retrieval 的趋势是什么？

## 【回答】

RAG 是**广义 Memory**：持久状态在**模型权重之外**，按需取回。它的关键问题与参数化记忆相同：**写入、寻址、使用、生命周期、成本**。

2026 年以来，**retrieval 正在变成可学习的策略**：模型自己决定**何时检索、缺什么、去哪里找、何时够用**——检索不再是固定的 pipleline 步骤，而是模型策略的一部分。

## 【问题】

Agent 时代记忆如何写入"经验系统"？2026 年 Self-Evolving Memory 的代表工作有哪些？

## 【回答】

- **Reflexion**：语言反思作为 **episodic memory**，等价于"**可读的 optimizer state**"；
- **Voyager**：技能库作为**程序化 Memory**，技能通过验证后才入库；
- **STOP / ADAS / AFlow / AlphaEvolve**：把 agent 结构、workflow、改进器本身当作**可演化程序**。

2026 年 Self-Evolving Memory 代表工作：

- **EvolveMem**：让**检索配置**与记忆内容一起演化；
- **CluE / BEHEMOTH**：**逐簇演化**抽取 prompt；
- **MemMA**：用**探针自检**，把使用端失败**回写成构建端修复**；
- **MemRL**：用 **Q 值**学习"哪些记忆值得被再次取出"。

## 【问题】

长期记忆评测（Benchmark）有哪些代表方向？看榜时要注意什么？

## 【回答】

长期记忆评测**尚无统一点数**，代表方向有 **LongMemEval、LongMemEval-V2、LoCoMo** 等。看榜前需确认测的到底是什么：

- 测"**记住后回答问题**"（Recall 能力）；
- 还是测"**管理长期记忆系统**"（写入/更新/遗忘全流程）；
- 还是测"**把记忆用于后续行动**"（决策与行动能力）。

三者考察的是完全不同的能力，不能混为一谈。
