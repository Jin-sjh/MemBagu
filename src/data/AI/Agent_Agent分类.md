# Agent分类

## 【问题】

从经典智能体理论看，Agent 有哪几类？各有什么特点？

## 【回答】

五类（LLM Agent 常是混合型）：

- **反应式（Reactive）**：输入→动作，几乎不维护复杂内部模型。优点：**快、可解释、易测试**；缺点：对**长程依赖与复杂推理弱**，遇未见输入可能失效，常与分层架构结合。
- **基于模型（Model-based）**：脑中有「世界模型」，能预测行动后果，显式维护状态机、仿真环境或知识图谱。
- **基于目标（Goal-based）**：明确要达成的状态、能选路径，关注「**是否达成**」。
- **基于效用（Utility-based）**：在多个**冲突目标间做权衡**（成本、时延、风险、用户偏好），选**综合最优**而非单点达成。
- **学习型（Learning）**：从反馈更新策略或模型（RLHF、在线反馈、Bandit 选工具）。

基于效用与基于目标的区别：目标型关注是否达成；效用型在多个冲突目标间权衡选期望效用最大。LLM Agent 一般算**混合型**：底层模型推理 + 上层目标/效用（打分选路径）+ 记忆（世界状态）+ 学习（反馈更新）。
