# 民主讨论模式如何避免空转

## 【问题】
民主协作（Joint Discussion）模式如何避免永远开不完会？适合生产吗？

## 【回答】
需要**硬终止条件**：
- **最大轮数**、**Token 预算**；
- **无新信息阈值**（连续两轮无实质变更则停）；
- 或**主席裁决**。

并配合**结构化发言**（观点 + 证据 + 反对意见）减少废话。

讨论适合生产吗？适合**低风险创意类或人类在环**；纯自动高风险决策通常要**仲裁 + 规则引擎**。若没有终止条件会 Token 爆炸、易空转与重复。
