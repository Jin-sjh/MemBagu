# 人类记忆类比

## 【问题】
用人类记忆模型设计 Agent 记忆有什么好处？

## 【回答】
好处是**模块化与可解释**：

- **感觉记忆**（极短、容量大、未加工）对应原始多模态输入缓存、流式 ASR 缓冲、截图/音频临时块；
- **短期/工作记忆**（容量小、可主动操作）对应对话上下文、Working Memory、ReAct 轨迹中的 scratchpad；
- **长期记忆**（持久、需巩固）对应向量库、文档库、用户画像表、知识图谱、会话摘要归档。

可针对不同模块设不同 SLA（延迟、持久化）。风险是类比不能硬套——计算机没有神经可塑性，需要工程上显式实现「巩固、遗忘、冲突解决」。**程序性记忆**常放在工具说明书、工作流模板、可执行策略（policy）或微调/少样本示例中，不一定进向量库。
