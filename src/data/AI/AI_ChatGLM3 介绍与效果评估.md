# ChatGLM3 介绍与效果评估

> 来源：「项目前预备知识」大纲（图片）。原文只给出知识点清单，未给出答案，
> 以下回答为根据公开资料（ChatGLM 官方仓库与公开评测榜单）整理，具体数字以官方最新公布为准。

## 【问题】

ChatGLM3 是什么？有哪些特点？

## 【回答】

**ChatGLM3 是智谱 AI（清华 KEG 实验室团队）开源的第三代双语（中英）对话大模型系列**。

**主要特点**：

- **模型家族完整**：包含 **ChatGLM3-6B（对话）、ChatGLM3-6B-Base（基座）、ChatGLM3-6B-32K（长上下文）** 等版本，覆盖不同场景。
- **能力升级**：**更强的语义理解、推理、代码与数学能力**，官方宣称在**语义、数学、推理、代码、知识**多个维度相比前代有明显提升。
- **原生工具能力**：官方强调**原生支持 Function Call（工具调用）**，并提供 **Code Interpreter（代码解释器）** 能力，便于构建 **Agent** 应用。
- **开源可商用**：模型权重**开源**，协议相对宽松，**便于本地私有化部署**（6B 规模对单卡/消费级显卡友好）。
- **部署生态**：与 **LangChain、LangChain-Chatchat、vLLM、 llama.cpp** 等工具链集成度好。

**工程意义**：6B 量级 + 中文强 + 可本地部署，使其成为**中文 RAG / Agent 项目选型中的常见基线模型**。

## 【问题】

如何评估 ChatGLM（及同类大模型）的效果？

## 【回答】

**1. 公开基准评测（通用能力）**

- **知识与推理**：**MMLU、C-Eval、CMMLU、AGIEval、GSM8K、MATH、BBH**。
- **代码**：**HumanEval、MBPP**。
- **中文场景**：**C-Eval、CMMLU、AlignBench** 是国内常用的中文评测集。

**2. 对话/对齐评测**

- **MT-Bench、AlignBench**：以**多轮开放问答 + 裁判模型（LLM-as-a-Judge）打分**评估对话质量。
- **人工盲评**：真实业务中最可信但仍昂贵的方式。

**3. 业务场景自建评测集（最关键）**

- 构造**贴近自身业务的评测集**（真实 query + 标准答案 / 评分 rubric）。
- 指标：**准确率、召回率、拒答率、格式合规率、有害输出率、首字延迟、成本**。
- **RAG 场景**另有专门指标：见 `大模型_RAG忠实度.md`（**忠实度 / 上下文相关性 / 答案相关性** 三元组）。

**4. 评估注意事项**

- **数据污染**：公开榜单可能包含训练语料，需关注**训练集重叠**。
- **Prompt 敏感性**：不同 **Prompt 模板与解码参数**会显著影响分数，评测须**固定模板并多次采样**。
- **分数不等于可用性**：榜单高不意味着**业务场景可用**，最终仍以**自建评测 + 线上 A/B** 为准。
