# 投票为什么不够_加权投票与评估器

## 【问题】
多 Agent 冲突解决里，为什么光有投票不够？Red Team 怎么用？

## 【回答】
因为 LLM Agent 的「独立意见」往往**不独立**（相似训练分布、相似 system 提示），且缺少真实世界证据时，投票可能**强化错误**（集体偏误）。更稳妥的是**证据门槛 + 优先级规则 + 人类在环**。

- **加权投票**：按权重而不是简单多数票（如安全意见权重更高）；
- **优先级仲裁**：规则「安全 > 产品 > 体验」，命中 CRITICAL/HIGH 直接 block_release；
- **基于证据的共识**：必须引用日志、测试结果、CVE 编号等技术证据；
- **Red Team**：专门 Agent 负责挑错、攻击假设、构造反例，输出**必须回应的质疑清单**。
