# 记忆图谱相对向量库的强弱

## 【问题】
记忆图谱比向量库强在哪里、弱在哪里？

## 【回答】
- **强**：实体—关系—实体（或超边）存储，检索用图遍历 + 向量，可解释、可推理**多跳关系**；
- **弱**：**构建成本高、实体对齐难**，对非结构化闲聊未必划算。

向量库擅长语义召回但难表达关系演化；二者可结合：图谱做关系骨架，向量做候选召回。记忆的反思（Reflection）周期性回顾轨迹生成高层见解，整合（Consolidation）把多条低层记录合并成稳定条目，减少冗余与冲突。
