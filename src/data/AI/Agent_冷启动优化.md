# 冷启动优化

## 【问题】
服务重启或新实例扩容时的冷启动（模型加载慢、缓存空、连接池未预热）怎么解决？

## 【回答】
分层预热（以下为该文档工程实践口径）：
- **模型预加载**：用 K8s readinessProbe，**模型加载完成前不接流量**；模型文件放共享存储避免重复下载；embedding + reranker 预加载约 30s。
- **缓存预热**：启动时加载 FAQ 与热门问题缓存，或从健康实例 peer 同步；预热未完成前降级（跳过缓存直接查）。
- **连接池预建**：启动即建最小数量 DB/Redis 连接并 PING 校验。
- **流量预热**：新实例先分配少量流量（权重渐增），避免冷请求集中打爆。
- 效果口径：**冷启动时间从约 120s 降到 45s，期间请求成功率从 70% 升到 98%**。工程要点是**把"首次请求代价"在就绪探针和预热阶段提前付清**。
