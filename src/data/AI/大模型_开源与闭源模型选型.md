# 开源与闭源模型选型

## 【问题】
开源模型相对闭源 API 的核心优势场景是什么？怎么选？

## 【回答】
- **开源核心优势**：数据不出域（隐私 / 合规）、可深度微调定制、长期成本可控（有算力前提下）、离线可部署。
- **闭源 API 优势**：上手快、持续升级、免运维，但依赖供应商、成本与合规需评估。
- 选型：**高合规 / 数据敏感 → 本地开源；快速验证 / 通用能力 → API**；混合架构常见（敏感本地开源 + 通用调 API）。看隐私、延迟、成本、定制需求与团队运维能力。
