# ReAct框架

## 【问题】

什么是 ReAct 框架？它的核心原理是什么？

## 【回答】

**ReAct 框架由 Yao 等人于 2022 年引入**（论文：https://arxiv.org/abs/2210.03629），核心思想是让 LLM 以**交错的方式**生成**推理轨迹（Reasoning Trajectories）**和**任务特定操作（Task-Specific Actions）**。其灵感来自"**行为（Act）与推理（Reason）之间的协同作用**"。**生成推理轨迹**使模型能诱导、跟踪和更新操作计划，甚至处理异常情况；**操作步骤**允许与外部源（如知识库或环境）交互并收集信息。ReAct 允许 LLM 与外部工具交互获取额外信息，从而给出更可靠和实际的回应。

**与 CoT 的关系**：链式思考（CoT）能执行推理轨迹，但**因缺乏与外部世界的接触或无法更新自身知识，导致事实幻觉和错误传播**；ReAct 则是**将推理与行为相结合的通用范例**，提示 LLM 为任务生成口头推理轨迹和操作。作者结论：**将 ReAct 和 CoT 结合使用**，同时使用内部知识和获取到的外部信息，**是最佳方法**。

## 【问题】

ReAct 的工作流程是什么？

## 【回答】

ReAct 的核心循环包含**三个关键步骤**：

1. **Thought（思考）**：模型生成推理轨迹，用于分解问题、提取信息、执行常识或算术推理、引导搜索和综合最终答案。
2. **Action（行动）**：模型执行具体操作，如搜索、查找等外部交互。
3. **Observation（观察）**：模型接收来自环境（如搜索引擎）的反馈信息。

这一循环**反复进行，直到模型能合成最终答案**。注意：不同类型的任务使用不同提示设置——以推理为主的任务（如 HotpotQA）使用多"思考-操作-观察"步骤；涉及许多操作步骤的决策任务则较少使用思考。

## 【问题】

请举例说明 ReAct 提示如何用于问答（HotpotQA）任务？

## 【回答】

ReAct 提示示例（摘自论文，简化为一个示例）——问题：`科罗拉多造山带东部区域延伸到的区域的海拔范围是多少？`。循环如下：

```
思考 1：我需要搜索科罗拉多造山带，找到东段延伸的区域，然后找到该区域的海拔范围。
操作 1：搜索 [科罗拉多造山带]
观察 1：科罗拉多造山带是科罗拉多及其周边地区造山运动的一段。
思考 2：它没有提到东部地区。所以我需要查一下东部地区。
操作 2：查找 [东部地区]
观察 2：(结果 1 / 1) 东部区域延伸至高平原，称为中原造山带。
思考 3：科罗拉多造山运动的东部区域延伸到高平原。所以我需要搜索高平原，找到它的海拔范围。
操作 3：搜索 [高平原]
观察 3：高平原指的是两个截然不同的陆地区域之一。
思考 4：我需要搜索高平原（美国）
操作 4：搜索 [高平原（美国）]
观察 4：高平原是大平原的一个分区。从东到西，高平原的海拔从 1800 到 7000 英尺 (550 到 2130 米) 不等。
思考 5：高平原海拔高度从 1800 到 7000 英尺，所以答案是 1800 到 7000 英尺。
操作 5：结束 [1800 到 7000 英尺]
```

## 【问题】

ReAct 在知识密集型和决策型任务上的表现如何？

## 【回答】

**知识密集型任务**（使用 **PaLM-540B** 作为基础模型）：
- 问答（HotPotQA）：ReAct **优于 Act（仅操作），但落后于 CoT**。
- 事实验证（Fever）：ReAct **优于 CoT**。

**误差分析**：CoT 的问题是**事实幻觉**；ReAct 的问题是**结构性约束降低其在制定推理步骤方面的灵活性**，且**很大程度上依赖检索到的信息**，非信息性搜索结果会阻碍推理并导致难以恢复。**关键发现**：结合 ReAct 和链式思考+自我一致性的提示方法通常**优于所有其他提示方法**。

**决策型任务**：在 **ALFWorld**（基于文本的游戏）和 **WebShop**（在线购物网站环境）上，ReAct 都**优于 Act**——没有思考的 Act 不能正确把目标分解为子目标；但基于提示的方法目前在这些任务上的表现与人类专家**相差甚远**。

## 【问题】

如何用 LangChain 实现 ReAct？核心优势有哪些？

## 【回答】

使用 LangChain 的 `initialize_agent`（agent="zero-shot-react-description"）可快速构建 ReAct agent，加载工具如 `google-serper`（搜索）和 `llm-math`（计算器）。示例查询："奥利维亚·王尔德的男朋友是谁？他现在的年龄的 0.23 次方是多少？"，agent 通过**思考→搜索→观察→计算器→最终答案**的循环，最终输出"哈里·斯泰尔斯，奥利维亚·王尔德的男朋友，29 岁。他年龄的 0.23 次方是 2.169459462491557。"

**核心优势**：1. **减少幻觉**（通过外部工具获取真实信息）；2. **提高可解释性**（推理轨迹让决策过程可理解可信）；3. **动态推理**（创建、维护、调整操作计划）；4. **处理异常情况**；5. **与 CoT 互补**（结合使用最优）。
