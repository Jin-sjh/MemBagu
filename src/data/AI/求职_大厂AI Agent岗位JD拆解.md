# 大厂AI Agent岗位JD拆解

## 【问题】
问：腾讯有哪些典型的 AI Agent 岗位？各自的核心要求与差异点是什么？

## 【回答】
文档归纳了腾讯三个代表性岗位，方向覆盖智能运维、后台开发与高级模型侧结合：

1. **智能运维 AI Agent 平台 · 资深软件开发工程师（北京）**
   - 基础要求：3 年及以上经验；本科及以上；Go / Java / C++ / Python 至少一种熟练。
   - 核心技能：**分布式系统、LLM、AI Agent、RAG、Prompt Engineering**。
   - 主要职责：异常检测、根因分析、任务规划、智能修复（或修复路径推荐与执行编排）。
   - 加分项：硕士/博士；AWS/Azure/GCP 公有云实践；可验证的开源贡献（PR、Issue、维护项目）。
   - 能力拆解：运维域 Agent 需理解**日志/指标/链路数据如何进入 RAG 或工具**；智能修复涉及**规划、工具权限边界、回滚与安全审计**，面试常追问「如何避免误操作」。

2. **AI Agent 后台开发工程师（深圳）**
   - 基础要求：本科及以上；Python / Go / C++ 等，3 年及以上后端开发经验。
   - 核心技能：**LangChain / LangGraph / AutoGen 等框架生态；RAG；Planning；Tool Calling**。
   - 学习侧重：能讲清**何时用 RAG、何时用工具、何时纯 CoT**，以及失败重试与超时策略。

3. **高级 AI Agent 开发工程师（深圳）**
   - 基础要求：5 年及以上；具备 LLM 应用或 Agent 实际开发经验（非仅调用演示）。
   - 核心技能：**SFT / RLHF / DPO 等对齐与微调方法；ReAct 等推理-行动范式；Fine-tuning；Kubernetes / Docker**。
   - 与其他腾讯岗位差异：更偏**模型侧 + 工程侧结合**——不仅要会编排，还要理解数据构造、训练/对齐流程、评估指标；K8s/Docker 强调训练/推理服务化、弹性扩缩、A/B 与灰度。

## 【问题】
问：小红书的 AI Agent 工程师（智能体系统与上下文工程）岗位重点考察什么？

## 【回答】
小红书内容社区属性强，Agent 方向与**搜索、推荐、创作助手、社区治理**等场景结合紧密。该岗位归纳要点：

- 基础要求：3 年及以上后端或 AI 工程经验。
- 核心能力：**意图识别、任务分解、工具调用、记忆管理、失败恢复**。
- 加分项：**Agent / Workflow 系统建设经验；RAG 工程；多模态**。

两个关键解读：

1. **「上下文工程」不止是 Prompt 写法**：还包括**会话状态、长期记忆、检索片段裁剪、多轮一致性、工具结果再注入**。
2. **失败恢复是高级岗位分水岭**：超时、工具报错、幻觉时应有**重规划、降级策略、用户澄清**机制。

## 【问题】
问：字节（剪映）的 AI Agent 后端开发岗位更侧重哪些工程能力？面试怎么准备？

## 【回答】
字节在剪映（CapCut）等产品线将 AI Agent 用于创作辅助、素材理解与流程自动化，后端强调**可扩展编排与成本控制**。文档归纳四个方向：

- **架构与编排**：LangGraph 架构与 Agent 编排——状态机、节点跳转、并行与同步。
- **记忆**：记忆槽位（Memory Slots）的数据结构设计——短期/长期、用户偏好、会话级与跨会话隔离。
- **成本与性能**：Token 消耗优化——摘要、缓存、模型路由、小模型兜底。
- **多 Agent**：子 Agent 动态分配——按任务类型或负载拆分子 Agent，需考虑调度与上下文传递。

面试准备建议：能画一张 **LangGraph 风格状态图**，标出入口、工具节点、结束条件、错误边；准备**记忆槽位 schema 设计**（如用户意图摘要、最近 N 轮工具结果、可检索的长期事实）；Token 优化准备 **2–3 个可量化手段**（滑动窗口摘要、工具输出截断策略、embedding 缓存命中）。

## 【问题】
问：把腾讯、小红书、字节三家岗位放在一起看，核心技能要求有哪些共性与差异？

## 【回答】
归纳三家 JD 的共性主线与差异：

- **共性（全员必备）**：**LLM 基础与 Prompt、RAG、Agent/Planning、Tool Calling** 是各厂高频要求；工程上普遍看重可落地、可观测、能扛线上。
- **腾讯差异**：岗位分层最明显——运维 Agent 岗强分布式与稳定性，高级岗强**对齐/微调（SFT/RLHF/DPO）与 K8s**。
- **小红书差异**：突出**上下文工程、记忆管理、失败恢复与多模态**，社区场景结合紧密。
- **字节（剪映）差异**：突出**图编排（LangGraph）、记忆槽位设计、Token 成本优化、多 Agent 动态调度**，后端成本控制显式要求高。

提示：以上为文档对公开 JD 要点的**归纳对比**，投递前务必以官网/招聘平台最新 JD 为准。
