# 大模型发展脉络

> 来源：「项目前预备知识」大纲（图片）。原文只给出知识点清单，未给出答案，
> 以下回答为根据公开资料整理，术语与结论以主流公开表述为准。

## 【问题】

什么是 Prompt（提示词）？它在与大模型交互中起什么作用？

## 【回答】

**Prompt 是用户输入给语言模型的指令或文本片段**，模型基于它做**下一个 token 的续写**。它是**不更新模型参数就改变模型行为**的最低成本手段。

- **组成要素**：通常包含**指令**（要做什么）、**上下文**（背景资料）、**输入数据**、**输出格式要求**四类信息。
- **提示词工程**：通过**角色设定、少样本示例、思维链（CoT）、输出约束**等手段提升效果。
- **Soft Prompt 与 Hard Prompt**：**Hard Prompt** 是人工可读的离散文本；**Soft Prompt** 是可学习的连续向量（如 P-Tuning / Prefix-Tuning），**不便于人读但可被训练**。
- **局限**：Prompt 受**上下文窗口**限制，且**不会把知识固化进参数**，需要长期稳定能力时通常要转向 **RAG 或微调**。

## 【问题】

「通向 AGI 之路」通常被概括为哪两个阶段？

## 【回答】

业界把通往通用人工智能的路径概括为**两个阶段**：

1. **第一阶段：知识（预训练）**——用**海量无标注语料**做自监督学习（如**预测下一个 token**），让模型**压缩并存储世界知识**，形成通识能力。产出是**基座模型（Base Model）**。
2. **第二阶段：对齐（微调 / 人类反馈）**——通过**指令微调（SFT）** 与**人类反馈强化学习（RLHF）**，把「会续写」的基座模型**对齐成会遵循指令、有helpful/honest/harmless 倾向的助手**。产出是**对话/助手模型**（如 ChatGPT、ChatGLM 这类 Chat 版本）。

**核心结论：先学知识，再学规范**——**预训练决定能力上限，对齐决定可用性**。

## 【问题】

语言模型（LLMs）的发展历程大致是怎样的？

## 【回答】

- **统计语言模型**：**N-gram**，基于**马尔可夫假设**用前 N-1 个词预测下一个词，**无法建模长距离依赖**。
- **神经网络语言模型**：**NNLM / word2vec** 引入**分布式词向量**，把词映射到低维稠密空间。
- **预训练范式**：**ELMo**（上下文相关词向量）→ **BERT**（**双向 Transformer 编码器 + MLM**）→ **GPT 系列**（**单向自回归解码器**）。
- **大模型时代**：**GPT-3** 展示**少样本/零样本上下文学习（In-Context Learning）** 能力；随后 **InstructGPT / ChatGPT** 加入**指令微调与 RLHF**，**GPT-4 / Claude / ChatGLM** 等在**多模态、长上下文、工具调用**上持续演进。
- **趋势关键词**：**规模定律（Scaling Law）**、**涌现能力**、**对齐**、**推理与工具使用（Agent）**。

## 【问题】

最近十年深度学习模型的主要迭代脉络是什么？

## 【回答】

1. **词向量阶段（~2013）**：**word2vec / GloVe**，解决**词的稠密表示**，但一词一向量、**无法处理一词多义**。
2. **序列建模阶段（~2014–2016）**：**RNN / LSTM / GRU + Seq2Seq + Attention**，缓解**长程依赖与变长序列**问题，但**串行计算无法并行**、长程仍会遗忘。
3. **注意力时代（2017）**：**Transformer** 提出 **Self-Attention + 位置编码**，**完全并行、长程建模强**，成为后续所有大模型的骨架。
4. **预训练时代（2018–2020）**：**GPT**（自回归解码器）、**BERT**（自编码双向）、**T5 / BART**（编码器-解码器），形成**预训练 + 微调**范式。
5. **大模型时代（2020 至今）**：**GPT-3 → ChatGPT → GPT-4/Claude/Gemini/ChatGLM 等**，叠加 **RLHF、MoE、长上下文、RAG、Agent、多模态** 等方向。
6. **工程侧演进**：**混合精度训练、KV Cache、Flash Attention、量化、蒸馏、LoRA 等参数高效微调**，解决**训练与推理成本**问题。

## 【问题】

为什么大模型有如此大的表现力？

## 【回答】

1. **参数规模与 Scaling Law**：**模型参数量、数据量、算力同步放大**时，损失按**幂律下降**，能力可预测地提升。
2. **Transformer + 自注意力**：**每个位置都能直接看到全局**，比 RNN 更擅长**长程依赖与复杂结构建模**，且**可大规模并行训练**。
3. **海量多样化语料**：参数中**隐式压缩了海量知识、语言结构与常识**，形成通识底座。
4. **涌现能力（Emergent Abilities）**：规模跨过阈值后，出现**少样本学习、思维链推理、代码生成**等在小模型上不存在的能力。
5. **上下文学习（ICL）**：**不更新参数**，仅靠 Prompt 中的示例即可**临时适配新任务**。
6. **对齐放大可用性**：**SFT + RLHF** 让模型能力被**稳定地表达为可交互的指令遵循行为**。
