# 关键路径分级与版本化

## 【问题】
如何做「关键路径」与「非关键路径」分级？

## 【回答】
- **关键路径**（支付、删数据）：强模型 + HITL + 审计；
- **非关键路径**（草稿、摘要）：小模型 + 宽松超时 + 积极缓存。

降级时关键路径保留同步强模型，非关键用弱模型，保障核心链路质量。

## 【问题】
为什么 Agent 更需要「版本化」的 Prompt 与模型？

## 【回答】
行为会随 **Prompt / 模型悄悄变化**，导致**线上回归难定位**。版本化可与 **Trace、评估集、回滚策略**一一对应。

实践：模型版本、Prompt 版本、工具清单版本一并记录到 Trace 与配置；**不可变发布**（如 `v20260401` 标签），避免「同名不同行为」。A/B 测试对 Prompt/模型/工具策略分流用户，比较任务成功率、成本、延迟、满意度，需统计显著性避免早停误判。
