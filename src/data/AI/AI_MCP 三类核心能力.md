# MCP 三类核心能力

## 【问题】
MCP（Model Context Protocol）提供哪三类核心能力？各自的用途是什么？

## 【回答】
MCP 是 Anthropic 提出的开放协议，为 LLM 应用提供标准化的外部上下文接入方式。它定义了三种原语（Primitives）：

### 1. Tools（工具）— 可执行的函数
- **本质**：让 LLM 能够调用外部函数执行操作，如查询数据库、发送消息、调用 API。
- **特点**：由模型控制执行时机（模型主动选择调用），服务器暴露工具列表，模型根据用户意图决定调用哪个工具。
- **典型场景**：数据库 CRUD、发邮件、创建文件、调用第三方 API。

### 2. Resources（资源）— 可读取的数据
- **本质**：暴露结构化的只读数据给模型，类似 GET 请求。模型可以像访问文件系统一样读取这些数据。
- **特点**：由客户端控制读取时机（客户端主动拉取），通过 URI 标识资源，支持文本和二进制内容。
- **典型场景**：读取文件内容、获取文档片段、查询知识库条目、API 响应数据。

### 3. Prompts（提示模板）— 可复用的提示
- **本质**：预定义的提示模板，帮助用户和模型快速开始特定任务。
- **特点**：服务器定义一组可复用的 prompt 模板，支持参数化，用户通过客户端选择和填写参数后使用。
- **典型场景**：代码审查模板、会议纪要模板、标准化问答流程。

### Tools vs Resources 的核心区分
| 维度 | Tools | Resources |
|------|-------|-----------|
| 操作性质 | 执行操作（写） | 读取数据（读） |
| 控制方 | 模型驱动 | 客户端驱动 |
| 有副作用 | 是 | 否 |
| 类比 | REST POST/PUT | REST GET |

MCP 通过这三类原语将 LLM 从封闭系统变为可连接外部世界的开放代理，是构建 AI Agent 的基础协议。
