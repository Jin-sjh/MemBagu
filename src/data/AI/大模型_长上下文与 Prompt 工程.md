# 长上下文与 Prompt 工程

## 【问题】
长上下文模型出现后，Prompt 工程会不会消失？

## 【回答】
- **不会消失，反而更需设计**：长上下文不是"随便堆字"的借口。
- 更需要**结构化（角色 / 任务 / 上下文 / 格式 / 约束）、检索与权限设计**；上下文越长，**间接注入与噪声干扰也可能越多**，需边界标记与清洗。
- Prompt 工程从"凑字数"升级为"可控、可审计、可防御"的工程设计。
