# RAG忠实度

## 【问题】

RAG 模型的忠实度研究关注什么问题？研究对象和方法是什么？

## 【回答】

RAG 忠实度研究基于 **Wu 等人（2024）**（arXiv: 2404.10198），核心是衡量 **RAG 与 LLM 内部先验知识之间的"角力"**——即当检索到的信息与模型自身知识不一致时，模型会偏向哪一方。研究对象：分析 **GPT-4** 及其他 LLM 在**问答任务**上的表现。核心实验：向模型提供**包含正确和错误信息的检索文档**，观察模型行为。

## 【问题】

RAG 忠实度研究有哪些主要发现？

## 【回答】

1. **忠实度提升**：当提供**准确的检索信息**时，能显著减少模型错误，准确率高达 **94%**——证明**高质量检索上下文对提升输出忠实度的积极作用**。
2. **幻觉倾向**：当文档中错误信息增多，且 LLM 的**内部先验较弱**（模型不太了解该话题）时，模型更容易"忠实于"检索到的错误内容，从而**产生幻觉或错误答案**。
3. **先验知识的抵抗力**：当 LLM 对某话题拥有**较强的内部先验**时，它对检索文档中的错误信息**具有更强的抵抗力**，不容易被误导。
4. **差异影响**：修改后的（错误）信息与模型先验的差异越大，模型选择采用这种错误信息的可能性就越小。

## 【问题】

RAG 忠实度研究的实际意义是什么？

## 【回答】

研究强调在生产环境中使用 RAG 系统时，**评估上下文信息（检索到的文档）质量**的重要性，特别是要**区分其支持性、矛盾性和错误性内容**。对开发者和公司而言：**不能盲目信任 RAG 的输出**，需要意识到**模型的内部知识和外部检索信息之间的复杂交互**，以及由此带来的**忠实度风险**。
