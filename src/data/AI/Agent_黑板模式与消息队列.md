# 黑板模式与消息队列

## 【问题】
黑板模式和消息队列有什么相似与不同？能结合吗？

## 【回答】
**相似**：都**解耦发送方与接收方**。

**不同**：
- **黑板（Blackboard）** 是**共享状态容器**（读最新快照），强调协作求解，像「会议室白板」；并发写需锁/版本，易成「垃圾堆」；
- **消息队列** 是**事件/任务的管道**，强调可靠投递、顺序、削峰，像「工单系统」；需死信与幂等设计（队列通常点对点消费一条，Pub-Sub 常是多订阅者各拿一份副本更偏广播）。

选型：强审计/强顺序/高吞吐 → 队列；探索式协作/快速原型 → 黑板；简单多角色 → 直接消息。

**能结合**：队列传事件，消费者更新黑板，兼顾可靠与共享状态。
