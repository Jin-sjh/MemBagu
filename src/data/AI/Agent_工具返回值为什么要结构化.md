# 工具返回值为什么要结构化

## 【问题】
工具返回值为什么要尽量结构化（JSON）？

## 【回答】
返回值会作为 `tool` 消息内容进入上下文，应**稳定、可解析**：优先 JSON 字符串，错误用统一结构 `{ "error": "..." }` 便于模型纠错。优点：

- 便于模型解析下一步推理；
- 便于程序校验与日志；
- 纯自然语言易产生歧义。

超大结果需**摘要或分页**（再提供 `fetch_more` 工具），避免撑爆上下文；二进制内容转文本描述或 URL，不要直接塞原始字节。例如 10MB 日志不应直接返回，应截断+摘要、写入对象存储返回链接、或提供 `grep_in_log` 等缩小工具。
