# 工具描述为什么是接口设计

## 【问题】

为什么工具描述（tool description）对 Agent 如此重要？它算不算接口设计？

## 【回答】

模型**靠描述做工具选择与参数填充**，描述就是 LLM 与工具之间的**人机接口（接口设计）**，直接决定成功率。描述不清会导致**选错工具、参数幻觉**。

好的描述应包含：**何时用、何时不用、参数含义、错误示例、返回格式**。工程上工具要有清晰 schema（名称、描述、参数 JSON Schema），遵循**最小权限、参数校验、错误信息回灌模型**。把工具描述当作接口来设计，是 Agent 成功率的关键杠杆。
