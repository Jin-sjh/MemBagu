# 金丝雀与蓝绿发布

## 【问题】
金丝雀发布要关注哪些指标？

## 【回答】
- **错误率、P95 延迟、Token 成本、业务指标**（任务完成率、用户投诉）；
- Agent 还应看**工具失败率、重试率、熔断率**。

## 【问题】
蓝绿部署与金丝雀发布如何取舍？Agent 长任务怎么做到部署不中断？

## 【回答】
- **蓝绿**：两套环境切换，回滚快，资源占用高；适合二进制切换、可接受双倍资源；
- **金丝雀**：小流量新版本，指标异常则回滚，风险更可控；适合渐进验证、对错误更敏感的生产流量，资源占用更平滑。

Agent 长任务部署不中断：用**任务队列与 Worker、可恢复状态（checkpoint）、K8s 优雅停机**（完成手头消息再退出）。
