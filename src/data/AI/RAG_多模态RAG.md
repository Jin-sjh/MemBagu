# 多模态RAG

## 【问题】
多模态 RAG 的要点是什么？图片和表格怎么进知识库？

## 【回答】
多模态 RAG 要点：**图像/表格编码、跨模态对齐、与文本混合索引与路由**。
- **图片**：含流程图/架构图时纯 OCR 不够，用**多模态模型（如 BLIP、多模态大模型）生成描述文本**再入库，或对关键图人工标注。
- **表格**：保留为 Markdown/HTML 表格字符串，或转 JSON 行记录存两份索引（自然语言版 + 结构化版）。
- **图文混排**：按阅读顺序拼接"图注 + OCR/Caption + 相邻段落"为一个块或父子块，保证上下文连贯。
检索时文本向量与图像/表格描述向量**混合索引**，路由到对应通道召回。
