# 结构化输出与后端校验

## 【问题】
为什么要让模型输出结构化结果（JSON / XML）？为什么还必须做后端校验？

## 【回答】
- **结构化输出便于程序消费**：用固定键名 / 类型的 JSON、Pydantic 校验、或 Function Calling 拿 tool_calls，下游解析稳定。
- **必须后端校验的原因**：模型**不保证 100% 合法 JSON 或满足业务约束**（可能多废话、尾逗号、类型错、越界）。
- 工程底线：**Prompt 要求"仅 JSON / 禁止 Markdown" + 服务端 JSON Schema 校验 + 失败 repair（二次调用修正）或 Function Calling 强校验**；关键路径用强校验兜底。
