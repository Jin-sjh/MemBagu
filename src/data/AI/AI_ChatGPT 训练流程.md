# ChatGPT 训练流程

> 来源：「项目前预备知识」大纲（图片）。原文只给出知识点清单，未给出答案，
> 以下回答为根据公开资料（InstructGPT / ChatGPT 公开论文与社区共识）整理。
> RLHF 的细节可对照 `强化学习_RLHF 的训练过程.md`、`强化学习_RLHF 与 PPO 的区别.md`。

## 【问题】

ChatGPT 是如何训练出来的？请说明完整流程。

## 【回答】

ChatGPT 类对话模型的训练是**「预训练 → 监督微调 → 奖励模型 → 强化学习」四步流水线**：

1. **预训练（Pre-training，基座模型）**
   - 数据：**海量无标注文本**（网页、书籍、代码等）。
   - 目标：**自回归预测下一个 token**，无监督/自监督。
   - 产出：**Base Model**——知识丰富，但**只会续写、不听指令**。

2. **监督微调（SFT，Supervised Fine-Tuning）**
   - 数据：**人工标注的高质量「指令-回答」对**（prompt + 理想回答）。
   - 目标：**有监督地学习按指令作答**，把续写行为**对齐为对话行为**。
   - 特点：**数据量小但质量极高**，是「对齐」的第一步。

3. **训练奖励模型（Reward Model, RM）**
   - 数据：对同一 prompt 采样**多个候选回答**，由标注者给出**好坏排序**。
   - 目标：训练一个**打分模型**，能对任意回答输出**人类偏好分数**。
   - 原因：**人类偏好难以写成显式损失函数**，用模型代替人工打分以支持大规模强化学习。

4. **强化学习优化（RLHF，典型用 PPO）**
   - 流程：模型**生成回答 → RM 打分 → PPO 更新策略参数**，反复迭代。
   - **KL 散度约束**：限制更新后的策略**不要偏离 SFT 模型太远**，防止**奖励黑客（Reward Hacking）** 与语言退化。
   - 产出：**InstructGPT / ChatGPT** 这类**更符合人类偏好**的助手模型。

**关键结论**：**预训练给知识，SFT 给格式，RM 给标准，RLHF 给偏好**；四步缺一不可。

## 【问题】

为什么不能直接只用 RLHF、跳过 SFT？

## 【回答】

- **冷启动问题**：基座模型**几乎不会按指令输出**，直接强化学习的**采样空间太大、奖励极稀疏**，学习效率低。
- **SFT 提供好的起点**：先把策略约束在**「合理的回答流形」**上，RLHF 只在附近**微调偏好**。
- **稳定性**：SFT 模型作为 **KL 惩罚的参考基准**，防止策略在强化学习中**跑飞或输出崩坏**。
- **成本**：人工写示范（SFT）比人工做大量排序标注**单位信息量更高**，先 SFT 更省标注预算。
