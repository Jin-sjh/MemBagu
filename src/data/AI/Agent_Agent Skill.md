# Agent Skill

## 【问题】

什么是 Agent Skill（智能体技能）？为什么需要它？

## 【回答】

Agent Skill 是一种**模块化、可复用的能力包**，通过提供**专业化的知识、工作流程和工具脚本**，扩展 AI 智能体的能力。它就像给 AI 准备的一份**"入职培训手册"**——将一个通用智能体转变为具备特定领域知识的专家；更形象地说，它不是简单地丢给 AI 一个工具（如一把扳手），而是**给它一套"高级技工培训手册"外加"专用工具箱"**，让它在需要时能迅速切换成某个领域的专家。

当前大语言模型虽然推理能力超强，但**无法将过往交互经验沉淀为长期工作记忆**，每次对话都像"恢复出厂设置"，用户不得不反复进行背景同步和流程教学。Agent Skill 解决了三个核心痛点：

1. **知识无法沉淀**：团队里"只会做一遍"的经验，无法被 AI 反复调用。
2. **上下文膨胀**：把所有专业指令塞进系统提示词，会让模型反应迟钝、抓不到重点。
3. **执行不一致**：同样的任务每次都要重新描述流程，结果参差不齐。

其核心目的是**把老手的经验打包，让通用模型变成某个领域的专家**。

## 【问题】

Agent Skill 的文件夹结构是怎样的？核心文件是什么？

## 【回答】

一个 Agent Skill 本质上是一个**文件夹**，其核心是 `SKILL.md` 文件。典型结构如下：

```
my-skill/
├── SKILL.md          # 必选：元数据 + 执行指令
├── references/       # 可选：深度参考资料
├── tools/            # 可选：辅助脚本
└── assets/           # 可选：静态资源（模板、图片等）
```

其中 `SKILL.md` 是**必选**文件，其余 `references/`、`tools/`、`scripts/`（可执行的 Python / Bash / JS 脚本）、`assets/` 均为可选。复杂一点的 Skill 还可以附带 `scripts/`（可执行脚本）、`references/`（按需查阅的文档）和 `assets/`（模板、图标等静态资源）。

## 【问题】

SKILL.md 由哪两部分组成？各起什么作用？

## 【回答】

`SKILL.md` 包含两部分：

- **元数据（YAML frontmatter）**：至少包含 `name`（技能名称）和 `description`（描述适用场景）。这是 **AI 判断何时使用该技能的依据**——模型根据 description 决定是否加载该 Skill。
- **指令正文（Markdown）**：详细的操作步骤、注意事项和示例，指导 AI 如何执行任务。

## 【问题】

什么是渐进式披露（Progressive Disclosure）？它的三层加载机制如何工作？

## 【回答】

渐进式披露是 Agent Skill 最精妙的设计，核心思想是**信息分三层按需加载**，既确保不遗漏细节，又避免一次性塞爆上下文。三层机制如下：

- **第一层：元数据（最轻）**：智能体启动时，只加载所有已安装 Skill 的 `name` 和 `description`，每个仅占**几十到一百来个 token**，装几百个 Skill 也不会影响性能。
- **第二层：SKILL.md 正文**：只有当模型判断当前任务与某个 Skill 的描述匹配时，才会把完整的 `SKILL.md` 读入上下文。
- **第三层：附加文件与脚本**：对于更复杂的场景，Skill 包含的脚本或额外文档仅在需要时才加载或执行。

这种机制就像一个组织良好的手册：**先看目录（元数据），再读具体章节（SKILL.md），最后查阅附录（附加文件）**。关于三层的更细拆解，可参见 `SKILL_三层渐进式披露架构.md`。

## 【问题】

Agent Skill、Prompt（提示词）、MCP（工具协议）三者有什么区别？

## 【回答】

三者定位互补，对比如下：

| 对比维度 | Prompt（提示词） | MCP（工具协议） | Agent Skill |
| --- | --- | --- | --- |
| 本质 | 一次性对话指令 | 连接外部工具的协议 | 封装领域知识的可复用能力包 |
| 解决什么问题 | 告诉模型"怎么做" | 告诉模型"能调什么工具" | 告诉模型"怎么把一件事做对" |
| 复用性 | 低，每次需重新编写 | 中，工具可复用 | 高，一次编写反复使用 |
| 上下文管理 | 全部塞入，易膨胀 | 按需调用 | 渐进式加载，高效管理 |

简单来说：**MCP 解决"能调什么工具"，Skills 解决"怎么把一件事做对"**，两者互补。

## 【问题】

Agent Skill 有哪些典型应用场景与示例？

## 【回答】

典型示例包括：

- **会议总结 Skill**：只需编写一个 `SKILL.md`，规定输出格式（参会人员、议题、决定、核心要点），AI 就能自动按规范总结会议内容。
- **ECS 实例查询 Skill**：包含查询脚本、状态码参考文档和输出模板，AI 按步骤执行查询并格式化输出。
- **PDF 处理 Skill**：`SKILL.md` 引用额外的 `forms.md` 文件，只有在需要填表时 AI 才会读取该文件。

实际应用中，一个 Skill 可以**小到"按特定格式总结会议"**，也可以**大到"完整的企业财务报告生成流程"**。

## 【问题】

Agent Skills 的生态与标准化现状如何？

## 【回答】

Agent Skills 由 **Anthropic 于 2025 年 10 月推出**，同年 **2025 年 12 月 18 日开源为跨平台开放标准**——Agent Skills Specification V1.0。TechCrunch 将其称为 **"AI 领域的 Dockerfile"**，让 AI 能力变得可移植、可组合、可版本控制。

截至 **2026 年 2 月**，公开可用的 Agent Skills 已**超过 85,000 个**，支持该标准的主流平台达 **27 家**，覆盖开发、设计、办公、电商、金融等领域。**Cursor** 是第一个全面采用它的 AI IDE，**微软 Azure AI Studio** 宣布原生支持，**GitHub Copilot Workspace** 也做了实验性支持。**Linux 基金会**也已启动讨论，拟将 Agent Skills 纳入其 AI & Data 基金会的候选标准之一。

Agent Skills 正在成为 AI 从"通用推理"走向"专业执行"的关键基础设施——开发者不再需要为每个场景训练或配置专用 AI，而是**给一个通用 AI 外挂各种能力包**，按需组合、灵活调度。
