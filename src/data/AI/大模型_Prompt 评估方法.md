# Prompt 评估方法

## 【问题】
怎么评估一个 Prompt 的好坏？

## 【回答】
- **离线指标**：准确率、格式合法率（能否 `json.loads`）、幻觉率、与标准答案一致性。
- **在线指标**：业务转化率、用户满意度、工具调用错误率；配合 A/B（唯一变量为 Prompt）。
- **对抗指标**：注入用例集（看是否越权 / 泄露）；记录模型版本，避免混测。
- 方法：固定评测集 + 评分标准，分类错误类型（理解错 / 知识错 / 格式错 / 安全错），小步修改一次一个变量。
