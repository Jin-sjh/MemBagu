# 检索增强生成研究综述

## 【问题】

RAG 的核心价值和工作流程是什么？

## 【回答】

**RAG 将输入与一组相关的支持文档结合起来**（通常来自维基百科等来源），文档被添加到输入提示中一起送入文本生成器。**核心价值**：解决 LLM **领域知识缺乏、信息准确性**问题与生成的**虚假内容**；适用于需要不断更新知识的知识密集型场景；**无需重新训练 LLM** 即可访问最新信息；生成可靠、基于检索的输出。**典型工作流程（四步）**：

1. **输入**：LLM 系统需要回答的问题
2. **索引**：将相关文档分块、生成嵌入向量、索引到向量库；查询内容也以相似方式嵌入
3. **检索**：通过比较查询内容与索引向量，找到相关文档
4. **生成**：将相关文档与原始提示结合作为额外上下文，传递给模型生成回答

## 【问题】

RAG 范式经历了哪些演变？各阶段特点与局限是什么？

## 【回答】

1. **初级 RAG（Naive RAG）**：采用传统过程（索引建立 → 文档检索 → 内容生成）。**局限**：低精确度、低召回率、可能接收到过时信息、导致不基于事实的幻觉性回答、信息重复或冗余、多文档优先级排序与风格一致性挑战。
2. **高级 RAG（Advanced RAG）**：解决检索质量问题，优化**检索前、检索时、检索后**三过程——检索前优化数据索引（数据细节度、索引结构、元数据、对齐方式、混合检索）；检索时改进嵌入模型（微调提高相关性、用动态嵌入模型如 OpenAI embeddings-ada-02）；检索后解决上下文窗口限制与噪音（重新排列文档、重算语义相似度、压缩提示信息）。
3. **模块化 RAG（Modular RAG）**：通过增强功能模块提升性能，支持按任务需求**添加、替换或调整模块**。**关键优化**：混合式搜索探索（关键词+语义搜索）、递归式检索与查询引擎（从小片段逐步检索更大内容块）、**StepBack-prompt**（引导概念与原则抽象化推理）、子查询策略（树状/按序查询拆分大查询）、**HyDE**（生成查询的假设性回答并嵌入，检索相似文档）。

## 【问题】

RAG 框架的核心组件（检索、生成、增强）如何优化？

## 【回答】

**检索技术**：提升语义理解——**数据分块策略**（按数据内容、应用需求、查询长度、词元上限选择，如句子转换器适合单句，text-embedding-ada-002 适合 256/512 词元）、专业领域嵌入模型微调（如 BGE-large-EN）；查询与文档精准匹配——**查询重写**（Query2Doc、ITER-RETGEN、HyDE）、查询嵌入优化；检索器与 LLM 协同优化——通过 LLM 反馈完善检索（AAR、REPLUG、UPRISE）、引入辅助工具（PRCA、RECOMP、PKG）。

**文本生成**：检索后处理与模型固定（信息简化减冗余、结果优先排序）；针对 RAG 系统的 LLM 微调（确保文本自然流畅且有效结合检索文档）。

**增强技术**：**增强阶段**——预训练（如 RETRO）、微调、推理；**增强数据源**三类——非结构化、结构化、LLM 生成数据；**增强过程三种**——**迭代检索**（多轮检索深化，如 RETRO、GAR-meets-RAG）、**递归检索**（一次检索输出作为另一次输入，如 IRCoT、Tree of Clarifications）、**自适应检索**（按需选择时机与内容，如 FLARE、Self-RAG）。

## 【问题】

RAG 与微调有何区别？如何评估 RAG 系统？

## 【回答】

**RAG vs 微调**：RAG 适用于融合新知识、快速适应新知识，**无需重新训练**，优势是可扩展应用、定制化反馈；微调适用于优化内部知识、输出格式、提升复杂指令执行，**需要重新训练**，优势是性能增强、效率提升。两者**可以相辅相成**，同时提示工程也能优化结果。

**评估**：**三大质量指标**——上下文相关性（检索信息精确度与相关度）、答案忠实度（答案对上下文的忠实反映）、答案相关性（答案与问题的契合度）；**四项能力**——对噪声鲁棒性、负面信息排除、信息整合能力、面对假设情况的鲁棒性。**评估工具**：基准测试 RGB、RECALL；自动化工具 **RAGAS、ARES、TruLens**；框架 RaLLe；检索指标 NDCG（归一化折扣累计增益）、命中率。

## 【问题】

RAG 研究面临哪些挑战与前景？有哪些代表性论文？

## 【回答】

**挑战与前景**：上下文长度问题（有效捕获最相关上下文）、系统鲁棒性（处理与现实相反和对抗性信息）、混合方法探索（RAG 与专门调整模型结合）、扩展 LLM 在 RAG 中的作用、规模化法则探究、生产级 RAG 挑战（性能、效率、数据安全、隐私）、多模态 RAG（图像、音频、视频、编码）、评价机制完善。

**代表性论文**（主要引用 Gao et al., 2023《针对大语言模型的检索增强生成：一项调查》，arxiv.org/abs/2312.10997）：**CRAG**（纠正检索增强，加自我修正组件，2024-01）、**RAPTOR**（递归嵌入聚类总结构建层次化总结树，2024-01）、**Self-RAG**（自我反思动态检索，2023-10）、**RAGAS**（自动化 RAG 评估，2023-09）、**GenRead**（LLM 先生成文档再提取答案，2023-09）、**FLARE**（主动检索，2023-05）、**RETRO**（从数万亿 Token 检索，2021-12）、**RAG 原始论文**（seq2seq 参数记忆 + Wikipedia 非参数记忆，2020-05）、**DPR**（密集段落检索，2020-04）。
