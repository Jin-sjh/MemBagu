# 多智能体容错与错误隔离

## 【问题】
多 Agent 系统的「容错」具体怎么体现？

## 【回答】
体现为**失败隔离 + 可替换性**：
- 审查 Agent 发现实现 Agent 的代码不合规，可**打回重写**而不污染主对话；
- 执行 Agent 沙箱崩溃可**只重启该步骤**；
- 工程上常配合**重试、指数退避、断路器、降级模板**。

会不会互相甩锅？**会**，所以需要**明确终止条件、主席/仲裁机制、可观测日志**。

## 【问题】
错误隔离在多 Agent 里如何实现？工具返回很大怎么办？

## 【回答】
- **沙箱执行**与**最小权限工具**；
- **校验 Agent 作为门禁**，不合规则拦截；
- **检查点**：通过后持久化，失败从检查点重试；
- **不把未经校验的自然语言当 API 参数**。

工具返回很大时：存对象存储，传**句柄/摘要**进上下文，避免撑爆上下文。
