# 记忆与 Tool Use 的边界

## 【问题】
记忆和 Tool Use 的边界是什么？

## 【回答】
- **工具（Tool Use）**解决「**当下获取外部世界状态**」——实时、动态；
- **记忆（Memory）**解决「**跨时间保留与回忆**」——稳定偏好、历史事件。

边界：实时动态数据（如实时库存）应走工具查；稳定偏好与历史事件（如「用户常买类目」）应走记忆或用户画像。二者互补：记忆决定「调哪个版本的你」，工具拉取「当下真实值」。
