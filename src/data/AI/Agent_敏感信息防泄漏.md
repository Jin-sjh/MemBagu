# 敏感信息防泄漏

## 【问题】
Agent 处理用户请求时会接触隐私/商业机密，怎么防止敏感信息通过 LLM 泄露？

## 【回答】
全生命周期脱敏 + 不可信原则（以下为该文档工程实践口径）：
- **输入脱敏**：正则 + NER 识别手机号/身份证/银行卡/邮箱/地址，替换为占位符（如 `[手机号_1]`），映射表仅存临时内存、会话结束清除。
- **输出还原**：返回前把占位符还原为原始值，**只还原用户有权看的信息**。
- **LLM 不可信原则**：敏感数据绝不发给 LLM；系统间通信 TLS 1.3。
- **日志安全**：日志落库前脱敏，访问最小权限。
- 要点：**脱敏-还原在网关/中间件层做，LLM 只见占位符**；**防泄漏要覆盖输入、输出、日志全链路**。
