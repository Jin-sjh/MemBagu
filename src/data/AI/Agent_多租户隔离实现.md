# 多租户隔离实现

## 【问题】
Agent 平台要同时服务多个企业客户，多租户隔离一般怎么实现？

## 【回答】
核心是**数据隔离 + 配置独立 + 资源配额**（以下为该文档工程实践口径）：
- **知识库隔离**：每个租户独立 Collection / 独立 schema，**严格按 tenant_id 过滤，避免跨租户查询**。
- **会话/缓存隔离**：对话记录独立存储；Redis 用 `tenant_id:` 作 key 前缀。
- **配置独立且可热更新**：每个租户可自定义 System Prompt、工具集、模型、检索策略，**配置存库支持热更新，无需重启**。
- **资源限制**：每租户独立 QPS 限流与 token 配额（如 Redis 令牌桶），超配额返回 429。
- 关键权衡：**隔离粒度要在"安全（零泄漏）"与"资源效率（避免每租户独占）"间平衡**；单租户异常不应影响其他租户。
