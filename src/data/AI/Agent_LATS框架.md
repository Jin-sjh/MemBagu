# LATS框架

## 【问题】

LATS 是什么？相比单次 ReAct 多花哪些成本、换来什么收益？

## 【回答】

LATS（Language Agent Tree Search）把 Agent 决策看成在**树上搜索**：节点是状态 / 中间思路，分支是不同行动；常与 **MCTS（蒙特卡洛树搜索）** 结合，通过**选择—扩展—模拟—回传**在探索与利用间折中，把「语言推理」嵌进搜索节点。

**成本**：来自**多分支扩展**与**多次评估 / 模拟**（工程难点是分支爆炸、评估器设计、延迟控制，需强剪枝与缓存）。

**收益**：**更系统的探索**，降低「一条路径走到黑」的局部最优风险，适合**决策点多**的任务（策略游戏、规划 puzzle、代码修复多方案补丁、研究型多假设验证）。

与 Beam Search 区别：Beam 偏序列生成，LATS / MCTS 更强调**节点价值估计与探索策略（UCB）**。相较 ReAct：ReAct 通常主路径贪心推进，LATS 通过多分支搜索与价值回传更系统探索决策空间（成本更高）。
