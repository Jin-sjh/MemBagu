# 模型参数设置

## 【问题】

大语言模型常用的可配置生成参数有哪些？各自的作用是什么？

## 【回答】

Prompt Engineering Guide（提示工程指南）介绍的常见可配置参数共 **6 个**：**temperature（温度）**、**top_p（核采样）**、**max length（最大长度）**、**stop sequences（停止序列）**、**frequency penalty（频率惩罚）**、**presence penalty（存在惩罚）**。它们用于控制生成结果的**确定性、多样性、长度与重复性**。调整参数设置对**提高响应可靠性**很重要，通常需要**实验**才能找到适合特定用例的正确设置，且最终生成结果会因所使用的大语言模型**版本不同**而异。

## 【问题】

temperature（温度）参数的作用是什么？不同任务应如何设置？

## 【回答】

`temperature` 参数值越小，模型返回**越确定**的结果；调高参数值，模型可能返回**更随机**的结果，带来更多样化或更具创造性的产出。**调低 temperature 实质上是在增加其他可能 token 的权重**。建议：**QA（问答）等任务设置更低的 temperature**，促使模型基于事实返回更真实、简洁的结果；**诗歌生成等创造性任务适度调高** temperature。

## 【问题】

top_p（核采样）是什么？与 temperature 有什么关系？

## 【回答】

`top_p` 与 `temperature` 配合被称为**核采样技术（nucleus sampling）**，用于控制结果的确定性。**只有 token 集合中包含 top_p 概率质量的部分才会被考虑用于响应**。**较低的 top_p 值会选择最有信心的响应**；**较高的 top_p 值会使模型考虑更多可能的词语**（包括不太可能的词语），导致输出更多样化。需要准确、事实性答案时**调低 top_p**，寻求多样化响应时**调高 top_p**。注意：**一般建议只调整 temperature 和 top_p 中的一个，不要两个都调**。

## 【问题】

如何控制模型的生成长度？max length 和 stop sequences 分别是什么？

## 【回答】

通过调整 **max length** 控制大模型生成的 **token 数量**，防止模型生成冗长或不相关的响应，同时**控制成本**。注意页面使用的是 **Max Length** 这一表述，与 API 中常见的 `max_tokens` 参数名**含义相同**。**stop sequence（停止序列）是一个字符串，作为生成终止标记**，阻止模型继续生成 token，用于控制响应长度和结构。示例：添加 `"11"` 作为 stop sequence，可以告诉模型生成**不超过 10 个项的列表**（模型在生成到 "11" 前会停下来）。

## 【问题】

frequency penalty 和 presence penalty 的区别是什么？

## 【回答】

两者都用于**惩罚重复 token**，但机制不同：

- **frequency penalty（频率惩罚）**：对下一个生成的 token 进行惩罚，**惩罚强度与该 token 在响应和提示中已出现的次数成比例**。frequency penalty 越高，某个词再次出现的可能性越小，从而**减少响应中单词的重复**。
- **presence penalty（存在惩罚）**：同样对重复 token 施加惩罚，但与 frequency penalty 不同：**惩罚对所有重复 token 是相同的**——出现 2 次的 token 和出现 10 次的 token 受相同惩罚，防止模型过于频繁地生成重复词。

建议：希望模型生成**多样化或创造性**文本 → 设置更高的 presence penalty；希望模型生成**更专注**的内容 → 设置更低的 presence penalty。注意：与 temperature/top_p 同理，**一般建议只调整 frequency penalty 和 presence penalty 中的一个，不要同时调整**。

## 【问题】

调整模型参数有哪些注意事项？

## 【回答】

1. **temperature 与 top_p 只调一个**，不要两个都调；**frequency penalty 与 presence penalty 同样只调一个**。
2. **调低 temperature 实质上是在增加其他可能 token 的权重**，理解这一点有助于解释输出变化。
3. 参数调整对**提高响应可靠性**很重要，可能需要**实验**才能找到适合特定用例的正确设置。
4. 最终生成结果可能因所使用的大语言模型**版本**而异。
