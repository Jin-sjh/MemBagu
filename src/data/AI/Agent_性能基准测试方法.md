# 性能基准测试方法

## 【问题】
怎么建立可重复的性能基准，作为优化参照和回归标尺？

## 【回答】
固定场景 + 固定数据集 + 变更前后对比（以下为该文档工程实践口径）：
- **基准场景**：单组件（向量检索/LLM/Rerank 延迟）、端到端（简单/RAG/工具调用延迟）、压力（最大 QPS/并发）。
- **工具**：pytest-benchmark 单组件、Locust 压测，结果存库对比。
- **固定数据集**：固定 100 条测试 query 覆盖各类，保证可比；重大变更前后各跑一次。
- **回归阈值**：延迟增加 > 10% 触发告警。
- 要点：**基准必须"同样本、可复现"才有意义，否则优化无从对照**。
