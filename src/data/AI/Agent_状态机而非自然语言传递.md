# 状态机而非自然语言传递

## 【问题】
多 Agent 系统为什么推荐状态机而不是纯自然语言传递一切？状态存在哪？

## 【回答】
自然语言灵活但**难校验、难回放、难测试**。状态机提供**可验证迁移、清晰终止、可观测指标**（卡在何阶段多久）。自然语言可作为**附件说明**，不应是唯一真相来源。

状态管理三要素：
- **全局状态共享**（Single Source of Truth，如数据库行 + 版本号），各 Agent 只通过 API 更新，避免各自复制矛盾副本；
- **状态机管理**（PLANNING → CODING → REVIEW → DONE），**非法迁移拒绝执行**，利于断点续跑；
- **事件驱动**：状态变更以事件发布，Agent 订阅关心事件而非轮询黑板。

状态存在哪？进程内只适合 demo；生产用 **Redis / DB 并加乐观锁**。
