# 熔断重试与指数退避

## 【问题】
熔断器和重试分别解决什么问题？一起用时要注意什么？

## 【回答】
- **熔断**防止故障扩散和雪崩（系统性故障时不再调用下游，给下游恢复时间）；
- **重试**提高偶发失败（网络抖动）的成功率。

一起用：熔断 Open 阶段**停止对同一下游的盲目重试**，改为**降级或切换供应商**；对 429 用限流 + 退避，避免放大拥堵。触发降级的条件：超时、5xx、429、熔断 Open、或质量评分低于阈值且允许降级（模型降级 / 功能降级 / 输出降级，并标注 degraded=true）。

## 【问题】
三态熔断器（Circuit Breaker）的三种状态是什么？半开放多少流量合适？

## 【回答】
- **Closed（闭合）**：正常转发，统计失败率 / 连续失败次数；
- **Open（打开）**：失败超阈值，快速失败（不再调用下游），进入冷却；
- **Half-Open（半开）**：冷却结束，放行少量探测请求，成功则回 Closed，失败则回 Open。

Half-Open 探测量：用令牌桶或固定并发 1～N 条探测，观察错误率，也可结合滑动窗口统计半开阶段成功率，避免一开就灌满。

## 【问题】
指数退避为什么要加 jitter（随机抖动）？哪些错误可重试？

## 【回答】
429 / 503 往往是瞬时过载，**立刻重试会加剧拥堵（惊群效应）**，退避把请求在时间轴上摊开。加 **jitter** 避免大量客户端在同一时刻齐刷刷重试，造成重试风暴。

公式：`wait = min(cap, base * 2^attempt + jitter)`。

- **可重试**：超时、连接错误、429、部分 5xx；
- **不可重试**：401 / 403、400（参数错误）、内容政策拒绝——应直接失败或换策略。
