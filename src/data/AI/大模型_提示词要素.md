# 提示词要素

## 【问题】

一个提示词（Prompt）可以包含哪些要素？

## 【回答】

提示词通常由以下四个核心要素组成：

1. **指令（Instruction）**：**想要模型执行的特定任务或指令**。
2. **上下文（Context）**：**包含外部信息或额外的上下文信息，引导语言模型更好地响应**。
3. **输入数据（Input Data）**：**用户输入的内容或问题**。
4. **输出指示（Output Indicator）**：**指定输出的类型或格式**。

需要注意：**并非所有要素都是必需的**——提示词所需的格式取决于想要语言模型完成的任务类型。

## 【问题】

如何用四要素构建一个文本分类的提示词？请给出示例。

## 【回答】

文本分类提示词示例如下：

```
请将文本分为中性、否定或肯定
文本：我觉得食物还可以。
情绪：
```

其中各要素对应关系为：

- **指令**："将文本分类为中性、否定或肯定"
- **输入数据**："我认为食物还可以"部分
- **输出指示**："情绪："（指定输出的类型/格式）

**注意**：此基本示例不使用上下文，但上下文也可以作为提示的一部分提供，例如**以其他示例的形式**出现，帮助模型更好地理解任务并引导预期的输出类型。
