# 代码执行工具的安全边界

## 【问题】
代码执行工具如何做到基本安全？

## 【回答】
代码执行是**高风险**能力，必须在**沙箱**（Docker、gVisor、WASM）中执行，限制 CPU/内存/网络，禁用危险模块；默认应关闭或仅对内网。配合：

- 超时控制；
- 只读默认；
- 审计日志；
- **生产慎用**。

数据库查询工具永远参数化查询、禁止字符串拼接 SQL，最好只允许只读账号 + 白名单表 + 行级权限；文件操作工具限制根目录（chroot 或路径规范化），禁止任意路径。
