# Agent落地最优先非功能需求

## 【问题】

企业内部落地 Agent，最先要关心的非功能需求是什么？哪些场景优先落地？

## 【回答】

三个最优先：**安全与合规**（权限、审计）、**可控性**（人在回路、工具白名单）、**可观测性**（轨迹、指标、回放）。再延伸是版本管理与灰度（Prompt / 工具 / schema 版本化、影子模式、金丝雀、一键回滚）。

落地场景按「**高频、可工具化、可评估**」优先选：

- **智能客服**：工单查询、订单状态，需知识库对齐、身份鉴权、升级人工；
- **代码助手**：读仓库、跑测试、提 PR，需沙箱、diff 审查、最小权限；
- **数据分析**：NL2SQL、制图、解读，需数据治理、行级权限；
- **自动化运维**：查日志、重启、开单，需审批流、灰度、回滚；
- **知识管理**：摘要、标签、关联检索，需溯源、版本、权限。

客服场景降幻觉靠强 RAG 溯源、禁止无引用断言、模板化答复、未知则转人工。
