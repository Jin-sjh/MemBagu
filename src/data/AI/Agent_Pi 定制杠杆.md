# Pi 定制杠杆

## 【问题】
Pi 没有 MCP、计划模式、子 Agent、loop 模式、待办等"商业 Agent 标配功能"，想要这些功能怎么办？「五根定制杠杆」指什么？

## 【回答】
答案藏在 §3.1 那句话里：**Pi 不给你计划模式，它给你构造计划模式所需的构建块**。Pi 提供五根杠杆让你把它塑造成想要的形状——**前四根用于自己用，第五根用于把成果分享出去**：

| 杠杆 | 作用 | 类比 |
|---|---|---|
| **扩展（Extensions）** | 给 Agent 加新能力（工具/命令/模式/钩子） | 拆开机器换零件 |
| **技能（Skills）** | 给 Agent 加新知识（"遇到 X 任务该怎么做"） | 按需加载的培训手册 |
| **提示词模板（Prompt Templates）** | 可复用工作流，支持参数 | 一键加载的操作 SOP |
| **主题（Themes）** | TUI 图形皮肤，实时重载 | 换肤 |
| **Pi 包（Pi Packages）** | 把前四样打包分发，npm/git 安装 | 发 npm 包 |

设计哲学：**极简的核心 + 强大的杠杆**。你拿到的是"一个能长成任何形状的 Agent"，而不是"一个被作者决定了长成什么形状的 Agent"。商业 Agent 把功能**焊死**在产品里，Pi 把它们**拆下来变成可选模块**。

## 【问题】
为什么说扩展（Extensions）是五根杠杆里最被低估、也是最强的一根？

## 【回答】
扩展是 **TypeScript 文件**，被 Pi **自动加载、支持热重载**——改一个扩展文件，正在跑的会话**立即生效，不用重启**。这看似小事，其实是个杀手锏：它催生了一种独特玩法——**让编码 Agent 自己改自己的能力**。

扩展能碰的东西很深：**工具、斜杠命令、键盘快捷键、事件钩子、整套 TUI 组件树**——Pi 把内脏都暴露给你了。Pi 仓库附了 **50 多个官方扩展示例**，社区观察者 Rushi 拆解过：那些你以为是默认行为的内置能力——**子 Agent、计划模式、权限门禁、沙箱、MCP 集成、自定义编辑器——全都可以作为扩展实现**。

三个实操例子（都来自官方/社区）：
- 想要 MCP？装一个 MCP 扩展即可；想要子 Agent？派生一个新的 Pi 实例的扩展就有现成的。
- 想要 **loop 模式**（让 Agent 自己迭代到任务完成）？写一个扩展**拦截 `turn_end` 事件再触发下一轮**就行。
- 有人**五分钟**写了一套 read、write、edit、bash，通过 **SSH 操作远程机器**，彻底替换掉内置工具；给 Pi 加**权限审批弹窗**（默认是 YOLO 模式）约 **50 行扩展代码**就够了。

一句话结论：**Pi 的能力，随你愿意定制它的意愿而线性增长**。

## 【问题】
Pi 的技能（Skills）和扩展（Extensions）有什么区别？「渐进式披露」解决什么问题？

## 【回答】
**技能是"指令 + 工具"打包的能力包**，采用**渐进式披露**——**只在被调用时才进上下文，平时不占一个 token**。它解决一个核心矛盾：**既想要丰富的能力库、又不想每个会话都为用不上的能力付上下文税**。

两者的分工可以这样理解：**扩展是给 Agent 加新能力**（加新工具、加新命令、加新模式），**技能是给 Agent 加新知识**（"遇到 X 任务该怎么做"）。而且两者**可以叠加**——一个扩展可以注册若干技能，一个技能也可以调用扩展提供的工具。

## 【问题】
提示词模板（Prompt Templates）和主题（Themes）分别是什么？

## 【回答】
- **提示词模板**：针对**重复性任务**的可复用 **markdown 模板，支持参数**。比如天天做 code review，可以写一个模板把"读 diff、检查风格、给反馈"的指令固化下来，需要时通过**斜杠命令一键加载**。
- **主题**：**TUI 的图形主题**，在会话进行中**切换、立即生效**。这是杠杆里最轻的一根，但对长期使用者很重要——你要看一个工具一整天，它得让你眼睛舒服。

## 【问题】
Pi 包（Pi Packages）是什么？它如何把"自己造"扩展到"社区共享"？

## 【回答】
**扩展、技能、模板、主题都可以打包成一个 Pi 包**，从 npm 或 git 安装：

```bash
pi install npm:@foo/pi-tools
# 或者直接从 git 仓库
pi install git:github.com/user/repo
```

这套模型和开发者每天都在用的**包管理器高度相似**，这种熟悉感是它被快速采纳的原因之一。你写好一个扩展发到 npm，**全世界任何 Pi 用户一行命令就能装上**——这把"自己造"的范围从"自己用"扩展到了"社区共享"。
