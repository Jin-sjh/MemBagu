# 人机在环

## 【问题】
为什么多 Agent 系统需要「人机在环」（Human-in-the-Loop）？

## 【回答】
- **高风险决策、未知法规、或模型置信度低**时，人类是**最后防线**；
- 同时可**收集真实反馈**迭代提示与工具。

人机在环在多处出现：动态任务分配需要 HITL 兜底、冲突解决需要人类仲裁、关键路径（支付/删数据）强制 HITL + 审计、工具调用两步授权中人工确认、降级时关键路径保留同步强模型。
