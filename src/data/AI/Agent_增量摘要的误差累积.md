# 增量摘要的误差累积

## 【问题】
增量摘要的误差累积怎么缓解？

## 【回答】
- **增量摘要**：新消息来了，把「旧摘要 + 新片段」再摘要，省算力与成本，但可能误差累积、早期细节被吞。
- **全量摘要**：定期对完整对话重摘要，更一致，但成本高、对话极长时仍可能触顶。

工程上常见：**增量在线 + 定期全量校准**。缓解累积：

1. 定期全量重摘要；
2. 摘要中保留关键事实清单（姓名、日期、硬约束）；
3. 对摘要做一致性检查（另一个小模型挑错）；
4. 让用户可编辑「长期事实」。
