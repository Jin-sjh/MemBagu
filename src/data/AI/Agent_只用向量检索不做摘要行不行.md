# 只用向量检索不做摘要行不行

## 【问题】
只用向量检索、不做摘要可以吗？

## 【回答】
可以，但你会**失去低成本的全局叙事**（例如任务阶段、未决事项）。摘要擅长提供「主线」，向量擅长提供「细节证据」。最佳实践常是**摘要 + 检索并存**：摘要把信息搬到更短载体，配合长期记忆检索，实现「短上下文 + 广记忆」。

若数据极结构化（如工单系统），可用**状态机字段替代部分摘要**。策略上分层：硬约束进结构化槽位，软偏好进摘要，细节进向量库按需检索。
