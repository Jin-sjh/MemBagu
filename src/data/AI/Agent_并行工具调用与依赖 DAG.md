# 并行工具调用与依赖 DAG

## 【问题】
并行工具调用要注意什么？

## 【回答】
无依赖的多个查询（查天气 + 查股价）可并行 HTTP 缩短延迟；OpenAI 一次 assistant 消息可返回多个 `tool_calls`。注意：

- **幂等性**（重试安全）；
- 后端并发限制与连接池；
- **写操作并行可能竞态**（需业务锁或串行）；
- 结果合并顺序；
- 部分失败重试策略（多工具并行时单个子失败可只重试该分支）。

## 【问题】
工具编排里的「依赖 DAG」是什么？并行和串行怎么取舍？

## 【回答】
把工具调用当**节点**、数据依赖当**边**，调度器拓扑排序执行，检测环、失败重试或补偿（长事务用 Saga 或幂等重试，AI 步骤用「检查点」持久化状态）。

取舍原则：**读多且无依赖并行**；有写冲突、强一致、或后一步参数必须来自上一步精确字段时**串行**；可并行读再串行写（视业务而定）。
