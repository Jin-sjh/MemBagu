# 用户反馈闭环

## 【问题】
AI 回答效果要靠用户反馈持续迭代，反馈怎么收集、怎么形成优化闭环？

## 【回答】
显式+隐式反馈 + 根因闭环（以下为该文档工程实践口径）：
- **收集渠道**：显式（每条回答"有帮助/无帮助"+文字）；隐式（重复提问、转人工、轮次过多说明不满意）；定期问卷。
- **处理流程**：反馈→自动分类（满意/不满意/建议）→不满意人工审核→根因分析（检索/生成/知识缺失/其他）。
- **数据驱动优化**：每周看不满意 Top10 类型，跟踪优化后指标，形成"问题-优化-效果"闭环；知识缺失回流知识库、Prompt 问题回流 Prompt 版本。
- 要点：**隐式反馈往往比显式更真实；反馈不闭环就只是摆设**。
