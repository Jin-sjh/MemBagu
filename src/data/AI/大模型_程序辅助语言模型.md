# 程序辅助语言模型

## 【问题】

什么是程序辅助语言模型（PAL）？它的核心原理是什么？

## 【回答】

**PAL（Program-Aided Language Models，程序辅助语言模型）由 Gao 等人（2022）提出**（论文：https://arxiv.org/abs/2211.10435）。该方法使用 LLM 读取自然语言问题，并**生成程序（代码）作为中间推理步骤**。**核心原理**：与思维链（CoT）提示的关键区别在于，PAL **不是使用自由形式文本来获得解决方案，而是将解决步骤卸载到类似 Python 解释器的编程运行时中**。流程架构：**提示（Prompt）→ 代码生成（LLM 输出 Python 代码）→ 程序执行器（外部 Python 解释器执行）→ 得到答案**。

## 【问题】

PAL 与思维链（CoT）有什么区别？

## 【回答】

| 维度 | CoT（思维链） | PAL（程序辅助语言模型） |
|------|--------------|----------------------|
| 中间推理形式 | 自然语言文本 | 可执行的程序代码 |
| 推理执行者 | LLM 自身 | 外部编程解释器（如 Python） |
| 计算可靠性 | 可能出现算术/逻辑错误 | 代码执行结果精确可靠 |
| 核心优势 | 简单直观 | 将计算任务卸载给确定性执行器 |

## 【问题】

请举例说明 PAL 如何用于日期理解任务？

## 【回答】

页面提供基于 **LangChain + OpenAI GPT-3（text-davinci-003）** 的完整实例（目标问题：`Today is 27 February 2023. I was born exactly 25 years ago. What is the date I was born in MM/DD/YYYY?`）。提示词采用**少样本（few-shot）**方式，包含多个日期理解任务示例，每个示例展示：1. 自然语言推理描述（`#` 注释形式）；2. 对应 Python 代码（用 `datetime` 和 `relativedelta` 计算）；3. 格式化输出。示例节选：

```
# Q: 2015 is coming in 36 hours. What is the date one week from today in MM/DD/YYYY?
# If 2015 is coming in 36 hours, then today is 36 hours before.
today = datetime(2015, 1, 1) - relativedelta(hours=36)
# One week from today,
one_week_from_today = today + relativedelta(weeks=1)
# The answer formatted with %m/%d/%Y is
one_week_from_today.strftime('%m/%d/%Y')
```

LLM 生成代码后，用 `exec(llm_out)` 执行，最终输出 `02/27/1998`。

## 【问题】

PAL 的关键特性与应用领域是什么？

## 【回答】

1. **中间表示形式**：代码而非自然语言。
2. **外部执行器**：依赖 Python 解释器完成计算，**避免 LLM 在算术上的不足**。
3. **少样本提示**：通过提供示例让 LLM 学会输出可执行的程序。
4. **应用领域**：适合**数学推理、日期计算、符号操作**等需要精确计算的任务。
5. **提示来源**：示例提示词来源于 PAL 的官方 GitHub 仓库（`pal/prompt/date_understanding_prompt.py`）。
