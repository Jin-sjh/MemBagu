# 大语言模型可信度

## 【问题】

什么是大语言模型（LLM）的可信度？可信 LLM 包含哪些关键维度？

## 【回答】

在**健康、金融等高风险领域**开发应用时，建立可靠的大语言模型尤为关键。虽然 LLM（如 ChatGPT）能生成易读回答，但在**真实性、安全性、隐私保护**等多个维度无法保证可靠性。**Sun 等人（2024）**（arXiv:2401.05561，论文《TrustLLM: 大语言模型的可信度研究》）全面讨论了可信度问题，提出**可信大语言模型的关键维度**（八个维度）及一个涵盖**六个维度**的评估基准。八个关键维度包括：

| 维度 | 说明 |
|------|------|
| **真实性** | 模型输出内容的真实与准确程度 |
| **安全性** | 防止模型被恶意利用、减少有害内容生成 |
| **公平性** | 避免产生刻板印象与歧视性输出 |
| **鲁棒性** | 面对对抗性攻击和异常输入时的稳定性 |
| **隐私保护** | 处理个人敏感信息时不泄露数据 |
| **机器伦理** | 对道德原则的理解与复杂伦理判断能力 |

（另外两个维度原文未逐一展开，涵盖在上述框架中。）

## 【问题】

TrustLLM 对 16 款主流 LLM 的评估有哪些关键发现？

## 【回答】

该项研究评估了 **TrustLLM 中 16 款主流大语言模型**，覆盖 **30 多个数据集**，关键发现：

1. 尽管在可信度方面**专有的大语言模型通常优于大多数开源模型**，但一些开源模型正在逐渐缩小差距。
2. **GPT-4 和 Llama 2** 能有效拒绝刻板印象陈述，并对**对抗性攻击**展现更强抵抗力。
3. **Llama 2** 等开源模型在未使用任何特殊内容审查工具的情况下，其可信度与专有模型相近；但某些模型在追求高可信度过程中**有时会牺牲特定任务性能**，将无害输入错误地视为有害内容。

## 【问题】

各可信度维度有哪些关键发现？

## 【回答】

- **真实性**：训练数据中的噪声、误导性信息或信息过时使 LLM 保持真实性面临挑战；但**能接入外部知识来源的模型**在真实性方面有所提升。
- **安全性**：相比专有模型，**开源 LLM 在处理潜在安全问题方面通常表现不佳**，平衡安全与灵活性是一大挑战。
- **公平性**：大部分 LLM 避免刻板印象做得不够好，即便先进的 **GPT-4** 在此领域准确率也仅约 **65%**。
- **鲁棒性**：LLM 在处理**开放式问题或非典型数据分布**时表现出较大不确定性。
- **隐私**：尽管 LLM 能识别隐私保护重要性，处理敏感信息表现大相径庭——在 **Enron 电子邮件数据集**测试中，一些模型出现**数据泄露问题**。
- **伦理观**：LLM 对道德原则有基本理解，但在处理**复杂伦理判断**时往往力不从心。

## 【问题】

LLM 可信度的评估工具和资源有哪些？

## 【回答】

研究者建立了展示不同模型在可靠性各维度表现的**排行榜**——"更可信的大语言模型在提升指标（标记为↑）上得分更高，在降低指标（标记为↓）上得分更低"。可在 GitHub 上找到一套完整评估工具包，用于跨多个维度测试 LLM 可信度：**https://github.com/HowieHwong/TrustLLM**（关联论文：Sun 等人 2024，arXiv:2401.05561）。
