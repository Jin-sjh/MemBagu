# 投机解码

## 【问题】
投机解码（Speculative Decoding）是怎么加速生成的？

## 【回答】
- **小模型（draft）先多步"提议"若干 token，大模型（target）并行一次性验证**：接受则一次前进多个 token，拒绝则从分歧点重采样。
- 本质：**用 draft 模型的廉价并行提议，把自回归的串行步数压短**，降低每 token 延迟（理想情况）。
- 前提：**draft 与 target 需兼容**（同词表 / 分布接近）；加速收益取决于 draft 接受率；属算法层优化，可与 vLLM 等集成。
