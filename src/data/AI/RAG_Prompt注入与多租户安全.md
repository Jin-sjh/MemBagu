# Prompt注入与多租户安全

## 【问题】
如何防止 Prompt 注入污染 RAG？

## 【回答】
RAG 的检索上下文来自外部文档，可能被植入恶意指令，需多层防御：
- **文档清洗**：入库前过滤/归一化，去除可疑指令片段。
- **权限隔离**：按租户/角色限制可检索范围。
- **输出引用限制**：要求答案必须基于检索片段、带出处，降低"凭空执行注入指令"。
- **检测异常指令模式**：对检索到的文本做异常指令检测。

## 【问题】
多租户 RAG 下最常见的安全事故是什么？怎么防？

## 【回答】
最常见是**检索未带租户过滤导致跨租户数据泄露**。
必须在**数据库层与查询层双重校验**：把 `tenant_id` 作为元数据强制过滤，物理隔离大客户（独立集群/命名空间），并按租户做配额与限流。
