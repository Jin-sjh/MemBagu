# 多Agent死循环检测

## 【问题】
如何检测多 Agent 系统的「死循环」？误杀怎么办？

## 【回答】
组合策略：
1. **全局步数上限**；
2. **状态哈希去重**（若连续重复同一计划/同一工具入参则停）；
3. **无进展检测**（关键指标多轮不变，如 bug 数未降）；
4. **预算熔断**（Token / 费用 / 时间）。

误杀怎么办？提高**进展定义粒度**、允许**人类确认继续**。

关联：民主讨论模式同样需要硬终止条件（最大轮数、Token 预算、无新信息阈值），否则 Agent 互相等待或重复同样计划会 Token 爆炸。
