# 栈和堆的区别

## 【问题】
栈和堆的区别

## 【回答】
栈由系统自动分配内存，空间小、存取速度快、遵循后进先出，存放基本数据类型与函数执行上下文，内存会自动释放；堆由程序员手动分配或引用类型自动分配，空间大、速度相对较慢，存放引用类型数据如对象、数组，需通过垃圾回收机制释放内存，栈存放堆中数据的引用地址，二者共同支撑 JS 的内存管理与数据存储。

---

## 真实业务 / 面试场景（案例补充）

### 场景 1：递归太深直接报错
**背景**：控制台报 `Maximum call stack size exceeded`。
**为什么**：JS 函数调用会在**栈**上压入执行上下文，栈空间很小（通常几 MB）。深层递归（如百万级树遍历）会瞬间打满栈。
**解决**：把递归改写成 `while` 循环，或用显式栈（数组）模拟递归。

### 场景 2：闭包导致内存下不来
**背景**：SPA 切走某个页面后内存不降反升，最终卡顿。
**为什么**：对象 / 数组存在**堆**上，闭包长期持有对大对象的引用，垃圾回收（GC）无法释放，造成内存泄漏；栈里的引用地址释放了，但堆上的对象还被闭包拽着。
**解决**：组件卸载（`beforeUnmount` / `useEffect` cleanup）时手动置 `null`、移除事件监听、断开定时器。

### 场景 3：函数传参是"传值还是传引用"
**回答要点**：栈里存的是值的拷贝——基本类型拷贝的是值本身，引用类型拷贝的是**堆地址**。所以修改形参的基本类型不影响外部，但修改形参对象的属性会影响外部（因为指向同一块堆内存）。
