# Axios 详解

## 1. Axios 是什么？解决了什么问题？

## 【问题】
Axios 是什么？解决了什么问题？

## 【回答】
Axios 是一个基于 Promise 的 HTTP 客户端，支持浏览器和 Node.js，对原生 XHR / http 模块进行了封装，提供了统一的请求 API、拦截器机制、自动转换数据、请求取消、并发控制等能力，适合在工程化前端项目中使用。

### 【隐含加分点】
- 浏览器端：基于 XMLHttpRequest
- Node 端：基于 http / https 模块
- 核心目标：统一请求层、可扩展、可维护

## 2. axios 请求失败处理方法

## 【问题】
axios 请求失败处理方法

## 【回答】
我在项目中会封装 axios 统一处理请求异常：

首先创建实例配置超时和基础路径，通过响应拦截器捕获网络错误、超时、4xx/5xx 及业务错误；

然后分类处理：网络异常提示网络问题，401 跳登录，403 提示无权限，服务端错误统一提示；

同时会做自动重试、取消重复请求、错误日志上报，最后返回标准化结果，保证代码健壮和用户体验。

## 真实业务 / 面试场景（案例补充）

### 场景 1：每个请求都手动加 token、手动 try/catch
**为什么**：散落各处重复且易漏。
**解决**：用请求拦截器统一在 `headers.Authorization` 注入 token；响应拦截器统一处理 401 跳登录、统一 toast 错误，业务代码只关心数据。

### 场景 2：用户快速连点，发了重复请求
**为什么**：上一个请求未返回又发一次，造成重复提交甚至重复扣款。
**解决**：用 `AbortController` 做请求取消（新请求进来取消上一个），或用"请求中"集合去重。

### 场景 3：弱网下请求一直转、无反馈
**解决**：配置 `timeout`（如 10s），超时后拦截器统一提示"网络开小差"，并可在 401 刷新 token 后自动重发一次。
