## 【问题】白屏问题应对总结

## 【回答】
1. 先查控制台：看 JS 报错、资源 404、跨域、CSP 等异常。
2. 再查网络：检查 JS/CSS 资源是否加载失败、接口是否阻塞。
3. 排查路由：history 模式需后端配置重定向，避免刷新白屏。
4. 排查构建部署：publicPath 配置错误、打包压缩异常会导致白屏。
5. 排查兼容：低版本浏览器不支持新语法，需添加 polyfill。
6. 兜底防护：页面加 loading、错误边界、全局异常捕获，减少白屏影响。

## 真实业务 / 面试场景（案例补充）

### 场景 1：上线后部分用户白屏，Sentry 报 chunk 加载 404
**为什么**：`publicPath` 配错或 CDN 没同步上传新 chunk，老用户缓存了旧 `index.html` 去请求已下线的 chunk。
**解决**：检查构建 `publicPath`、确认 CDN 资源齐全；用文件名 hash + 服务端返回正确资源。

### 场景 2：history 模式刷新白屏（404）
**为什么**：`history` 模式 URL 没有 `#`，刷新时浏览器直接向服务端请求该路径，服务端没配置兜底路由就 404。
**解决**：Nginx `try_files $uri /index.html`；或改用 `hash` 模式避开。

### 场景 3：某低版本安卓白屏，新安卓正常
**为什么**：代码用了可选链 `?.`、空值合并 `??` 等新语法，老浏览器不认识直接解析报错中断渲染。
**解决**：Babel `preset-env` + `targets` 配到对应浏览器，或加 `core-js` polyfill 做语法降级。
