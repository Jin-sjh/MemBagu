# split() 与 join() 的区别

## 【问题】
请指出 split() 与 join() 函数的区别。

## 【回答】

### 核心区别

**split()** 将字符串切割成数组，是关于**字符串**的方法；
**join()** 将数组转换成字符串，是关于**数组**的方法。

### 详细说明

对数组执行 **join()** 函数，然后通过参数分隔符字符串将它们连接起来，从而返回一个字符串。

对字符串执行 **split()** 函数，然后在参数分隔符处将其断开，从而返回一个数组。

### 简单总结

- **split()**：把一个字符串（根据某个分隔符字符串）切割成若干个字符串并存放在一个数组里
- **join()**：把数组中的字符串连成一个长串，可以认为它是 split() 的逆操作

## 真实业务 / 面试场景（案例补充）

### 场景 1：把 "a,b,c" 变成 "a-b-c"
**背景**：后端返回逗号分隔的字符串，前端要展示成横杠分隔。
**解决**：`"a,b,c".split(',').join('-')` —— split 按逗号切成数组，join 用横杠拼回，是经典的一行转换。

### 场景 2：解析 URL query 字符串
**背景**：`"a=1&b=2"` 要变成对象 `{a:'1', b:'2'}`。
**解决**：`str.split('&').map(p => p.split('='))` 先按 `&` 切、再按 `=` 切；注意 value 本身含 `=` 时要限制 split 次数（如 `p.split('=', 2)`）。

### 场景 3：split 的第二个参数 limit 坑
**要点**：`"a,b,c,d".split(',', 2)` 只返回前 2 段 `["a","b"]`，limit 限制返回数组长度；分清 split 是"字符串方法"、join 是"数组方法"，别把对象类型用错。
