# HTTP 请求方法

## 6. 常见的 HTTP 请求方法

## 【问题】GET 方法的作用是什么？

## 【回答】用于请求获取资源。

## 【问题】POST 方法的作用是什么？

## 【回答】用于提交数据，通常用于创建或修改资源。

## 【问题】PUT 方法的作用是什么？

## 【回答】用于更新资源。

## 【问题】DELETE 方法的作用是什么？

## 【回答】用于删除资源。

## 【问题】HEAD 方法的作用是什么？

## 【回答】类似于 GET，但只请求头部。

## 【问题】OPTIONS 方法的作用是什么？

## 【回答】用于获取支持的请求方法或查询服务器支持的选项。

## 【问题】PATCH 方法的作用是什么？

## 【回答】用于部分更新资源。

## 真实业务 / 面试场景（案例补充）

### 场景 1：面试高频——GET 和 POST 的区别
**要点**：GET 参数在 URL（有长度限制、可被缓存/记录在历史、相对不安全），用于获取资源；POST 参数在请求体（无长度限制、不被缓存、更安全），用于提交/创建。语义上 GET 应幂等、POST 不保证幂等。

### 场景 2：PUT 和 PATCH 怎么选
**背景**：更新用户信息，是全量更新还是只改昵称。
**解决**：PUT 语义是"替换整个资源"（全量），PATCH 是"部分更新"（只传要改的字段）。只改昵称用 PATCH 更省流量、更安全。

### 场景 3：RESTful 设计里方法即语义
**应用**：`GET /users` 列表、`POST /users` 新建、`PUT /users/1` 整体更新、`DELETE /users/1` 删除，用方法本身表达操作意图，而非把动作写进 URL。
