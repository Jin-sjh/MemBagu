# Vue 首屏加载优化

## 【问题】
Vue 首屏加载优化有哪些方案？

## 【回答】
Vue 首屏加载优化的主要方案有：

### 1. 压缩代码
使用 UglifyJsPlugin 等工具压缩 JavaScript 和 CSS 代码，减少文件大小。

### 2. CDN 加速
将静态资源（如 CSS、JavaScript、图片等）托管到 CDN 上，利用 CDN 的全球节点分布，加快资源的加载速度。

### 3. 路由懒加载
将路由组件分割成多个小的代码块，当路由被访问时才加载对应的组件，减少首屏加载的代码量。

### 4. 按需加载组件
对于一些不常用的组件，可以采用按需加载的方式，只有在需要使用时才加载。

### 5. 使用 v-once 或 v-if
避免不必要的渲染。

### 6. 使用<KeepAlive>缓存不经常切换的组件
减少组件的重新渲染。

### 7. 使用<Suspense>组件来处理异步组件的加载状态
在异步组件加载时显示占位内容。

### 8. 代码分割和动态导入
使用 Webpack 的 Tree Shaking 特性减少打包体积。

### 9. 优化资源加载
如图片懒加载。

## 真实业务 / 面试场景（案例补充）

### 场景 1：路由懒加载把首屏 JS 从 2MB 降到 400KB
**背景**：一个 Vue 后台项目打包后单文件 2MB，首屏白屏好几秒。
**解决**：把各路由组件改成动态 `import()`（懒加载），首屏只加载当前路由所需代码，其余按需加载；体积骤降、首屏明显变快。

### 场景 2：用 CDN 引入大体积基础库
**背景**：vue、element-plus、echarts 体积大，打进业务包拖慢首屏。
**解决**：这些稳定大库走 CDN（带缓存、就近节点），业务包只保留自己的逻辑，结合"压缩 + Tree Shaking + 图片懒加载"组合拳。

### 场景 3：面试——首屏优化从哪几层入手
**要点**：网络层（CDN、压缩、HTTP/2）→ 体积层（路由懒加载、Tree Shaking、按需引入）→ 渲染层（骨架屏、图片懒加载、KeepAlive 缓存）；用 Lighthouse / Web Vitals 量化 FCP、LCP 来验收。
