# Vue 什么是 Vue.js

## 【问题】
什么是 Vue.js？

## 【回答】
Vue (发音为 /vjuː/，类似于 view) 是一套用于构建用户界面的渐进式 JavaScript 框架。

**构建用户界面**：Vue 的核心库只关注视图层（宁在网页上看到的部分）。它使用"模板"将数据渲染到 DOM (网页)。

**渐进式框架**：这是 Vue 的核心理念。

a. **易于上手**：宁可以像使用 jQuery 一样，仅通过 `<script>` 标签将其引入现有项目，用于增强某个页面。

b. **逐步扩展**：当应用变得复杂时，宁可以引入 Vue Router（路由）、Pinia（状态管理）等官方工具，构建一个功能完备的单页应用 (SPA)。

---

## 真实业务 / 面试场景（案例补充）

### 场景 1：老 jQuery 项目只想给一个模块加交互
**背景**：一个旧后台系统用 jQuery 写成，不可能整体重写。
**解决**：在单个页面用 `<script>` 引入 Vue，只把"新增的筛选模块"用 Vue 写，其余不动——这正是"渐进式"：按需引入，不强推整套架构。

### 场景 2：业务变复杂后平滑升级成 SPA
**背景**：页面越来越多，需要前端路由和共享状态。
**解决**：再引入 Vue Router（路由）、Pinia（状态管理），把多页面后台渐进升级成单页应用，而不是一开始就上重架构。

### 场景 3：面试——"渐进式框架"是什么意思
**要点**：核心库只管视图层、可独立用；需要更多能力时再逐步叠加官方生态（Router/Pinia/Vite 等），项目能"由小到大"平滑扩展，没有强制的全家桶绑架。
