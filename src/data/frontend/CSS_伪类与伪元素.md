# 伪类与伪元素

## 【问题】
伪类和伪元素有什么区别

## 【回答】
**伪类用 `:` 描述已有元素的状态或结构匹配**，如 `:hover`、`:focus-visible`、`:nth-child`、`:has`；**伪元素用 `::` 表示由 CSS 生成的抽象子内容**，如 `::before` / `::after`。伪类是“给已有元素加条件”，伪元素是“凭空生成一个可装饰的盒子”。

---

## 【问题】
`:nth-child` 和 `:nth-of-type` 有什么区别

## 【回答】
**`:nth-child` 按所有兄弟计数**；**`:nth-of-type` 只按同标签类型计数**。例如 `li:nth-child(2)` 要求该 `li` 是父元素所有子节点里的第 2 个；而 `li:nth-of-type(2)` 只要求它是 `li` 这类标签里的第 2 个，不受其它标签干扰。

---

## 【问题】
伪元素能直接用 JavaScript 绑定事件或单独查询吗

## 【回答】
**不能**。伪元素不是通常意义上的 DOM 节点，不能直接用 JavaScript 绑定事件或单独查询；需要交互时应使用真实元素。`before` / `after` 适合做装饰，不适合承载必须被读屏、复制或交互的业务内容。

---

## 【问题】
`:not` 和 `:has` 有什么作用？使用要注意什么

## 【回答】
**`:not` 用于排除匹配**；**`:has` 提供关系选择能力**（例如选择“包含某子元素”的父元素）。使用时要考虑浏览器支持和选择范围，避免范围过大影响性能和可维护性。

---

## 【问题】
`:focus-visible` 有什么作用

## 【回答】
**:focus-visible 让键盘用户看到焦点而减少鼠标场景的视觉干扰**。键盘操作时显示焦点环以辅助可访问性，鼠标点击时不强制显示焦点环，兼顾可访问性与视觉体验。
