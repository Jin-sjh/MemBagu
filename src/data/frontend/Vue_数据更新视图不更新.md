# 数据更新视图不更新

## 【问题】
Vue 中数据更新了但视图不更新，是什么原因？怎么解决？

## 【回答】
常见原因与对应解法：

1. **未在响应式对象上进行数据修改**：Vue 2 的 `Object.defineProperty` 只劫持已有属性，新增/删除属性无法被侦测，解决方式是 Vue 2.x 使用 `this.$set()`（删除用 `this.$delete`）；Vue 3 基于 Proxy，直接在响应式对象上属性赋值即可触发更新。

2. **未使用正确的方式更新数组**：Vue 2 无法侦测数组下标直接赋值和 `length` 修改，需使用 `push`、`pop`、`shift`、`splice` 等变异方法（Vue 2 已重写这些方法），或用 `$set`、返回新数组整体替换。

3. **作用域问题**：修改的并不是当前组件实例上的响应式数据（如 `this` 指向错误、改到了组件外或闭包里的同名变量），视图自然不更新。

4. **Vue 实例未正确创建和更新**：数据未在 `data` 中预先声明（不在响应式系统内），或实例未正确挂载/更新，需保证数据初始化在 `data` 中、实例生命周期正常。

5. **未使用 `v-bind` 或 `:` 绑定**：模板中把属性写成了静态 HTML attribute 字符串，没有用 `v-bind`/`:` 动态绑定，数据变化不会同步到视图。

## 【考察点】
- Vue 2 响应式的两个已知局限：对象新增/删除属性、数组下标与 `length`
- `this.$set` 的适用场景与 Vue 3 Proxy 对这些问题的根治
- 响应式数据必须预先在 `data` 中声明
