# 从图片/链接提取面试题目 — 实操指南

本文件是 `interview-extractor` 的「从资料提取」实操参考。当用户**扔进来一张图片（截图）或
一个链接**，希望从中提取面试题目并按公司、岗位整理时，按本指南操作。

核心原则：**只做提取与整理，不编造答案**。资料里有问题+回答的都提取；资料只有问题没有
答案的，附加「回答建议」，并明确标注这是整理而非原文。

## 1. 资料接入方式

| 资料类型 | 接入方式 | 备注 |
| --- | --- | --- |
| 图片 / 截图（`.png/.jpg`） | 用 `read_file` 直接读图（多模态） | 读取图中文字后再提取，图片可能含多页截图 |
| 网页 / 文章链接 | 用 `web_fetch` 抓取正文 | 优先抓正文，忽略导航/广告；微信文章若抓取受限，请用户粘贴正文 |
| 粘贴文本 | 以粘贴内容为准，直接用于提取 | 最常见补充方式 |
| 多个来源 | 逐个接入，归并到同一批提取任务 | 同公司岗位合并去重 |

## 2. 提取「公司 / 岗位 / 轮次」元数据

先从资料中识别三个关键元数据（写入 frontmatter）：

- **company（公司）**：资料中出现的企业名，如字节跳动、腾讯、阿里巴巴、美团、拼多多等；
  可能是「字节」「腾讯」简称，规范为全称或常用名。
- **position（岗位）**：如大模型算法岗、前端开发岗、后端开发岗、测试开发岗、产品经理岗等。
- **rounds（轮次）**：资料中出现的面试轮次，如一面、二面、三面、HR面、主管面；
  用数组列出，如 `[一面, 二面, HR面]`。

识别不到时如实标注「未提及」，不要猜。

## 3. 提取面试问题（核心）

### 3.1 资料本身是面经问答（有显式问/答）

- **忠实保留**原意与关键术语，只做格式归一（统一为 `## 【问题】` / `## 【回答】`）。
- 按轮次组织：同一轮次的问题尽量集中，问题正文前注明轮次（如「一面：……」）。
- 相同或相似问题（不同轮次反复问）合并为一条更完整的问答。

### 3.2 资料只有问题没有答案（常见于面经清单）

- 问题原样提取，写入 `## 【问题】`。
- `## 【回答】` 内写**回答建议**：根据公开知识/项目已有条目整理答题要点，开头明确标注：
  `> 回答建议（资料未提供原文答案，以下为根据公开资料的整理）`。
- 回答建议要**保守、可验证**：涉及公司内部信息或不确定的细节，标注「待补充」，不要编造。

### 3.3 资料是讲解/招聘 JD（无现成问答）

- 从 JD 或岗位描述中提炼「该岗位可能被考察的问题」：如 JD 写「熟悉 React 和 Vue」，
  可提炼「React 与 Vue 的核心区别是什么？」。答案从 JD 与公开资料提炼，标注为回答建议。
- 这类提取要克制：只提炼有依据的问题，不臆造离谱问题。

### 3.4 面试题中的代码题/手撕题

- 若资料出现算法题或手写题（如「手写 PPO」「实现防抖节流」），单独成 `## 【问题】`，
  并可在 `## 【回答】` 中给出思路要点，或放 `## 【代码】` 增强块。
- 若题目本身需要写代码，且资料未给出，标注「代码待补充」。

## 4. 分类定位

- **library**：固定 `面经`（`src/data/面经/`，面经为独立题库库，不再按岗位方向拆分）。
- **category**：固定 `面经`。
- **topic**：公司+岗位，如 `字节大模型算法岗`。
- 同公司同岗位多篇（秋招/春招/社招）用文件名后缀区分，如 `面经_字节大模型算法岗_秋招.md`。

## 5. 查重与合并

写入前运行 `scripts/scan_entries.py` 查看是否已有同公司同岗位的面经文件：

- **已存在**：读取原文件，把新问题合并进去 —— 相同问题用更完整回答覆盖/补充，全新问题追加，
  frontmatter 的 `rounds`/`tags` 同步并集，`created` 保留首次日期。
- **不存在**：新建文件，按 `format-spec.md` 格式化。

禁止创建 `面经_xxx2.md` 这类副本文件。

## 6. 质量约束

- **不编造**：公司/岗位/轮次识别不到就标注，回答建议必须可验证并注明。
- **保真**：术语、代码、数字保留原文，不擅自润色。
- **去重**：先 scan，已存在则合并。
- **预览**：落盘前用 SKILL.md Step 6 预览，让用户确认范围与条数（资料量大时尤其重要）。

## 7. 提取示例

资料（一张截图，内容为某公司前端面经清单）：
> 腾讯一面：1. 讲一下闭包 2. 事件循环 3. 手写节流 4. V8 垃圾回收

提取产出（节选）：
```
## 【问题】
一面：什么是闭包？有什么作用？

## 【回答】
闭包是**函数与其词法作用域的组合**，内层函数可访问外层函数变量，常用于**数据私有化**与
**柯里化**。回答建议（资料未提供原文答案，以下为根据公开资料的整理）。

## 【问题】
一面：手写节流函数。

## 【回答】
节流指**固定时间间隔内只执行一次**。典型实现用时间戳或定时器，适用于滚动、resize 高频触发场景。
> 回答建议（资料未提供原文答案，以下为根据公开资料的整理）。
```
